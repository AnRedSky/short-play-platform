# 后端跟进待办（Mock → 真实 API）

当前前端只对接 mock 契约，页面与 `services/<domain>/index.ts` 已收敛。以下任务按依赖顺序推进，完成一项即可替换对应 service 内部实现，页面不改。

## 一、接口与契约

| ID | 任务 | 关键内容 | 验收 |
| --- | --- | --- | --- |
| B-01 | 项目域契约定稿（完成，草案见 `docs/04-api/openapi-projects.yaml`） | `projects` 列表/详情/汇总/流水线/时间线；字段统一（code/title 与前端 id/name 的映射层） | OpenAPI 草案 + 与 mock 响应结构一致 |
| B-02 | 状态机服务端化 | 15 状态、动作键、权限、原因校验；非法迁移返回 409；`project_id + action + expected_state` 幂等 | 全部动作有服务端用例，重复提交不双写 |
| B-03 | 身份与权限 | 36 个权限码、身份/角色/部门映射；路由级与接口级双重鉴权；身份切换仅测试环境 | 6 类身份 × 56 路由权限矩阵通过 |
| B-04 | 剧本与审核 | 版本链、锁定、审核清单；一个事务内完成 review + 状态迁移，禁止双迁移 | 审核通过/退回各一条集成用例 |
| B-05 | 生成任务与队列 | 任务创建、排队、重试、取消、暂停；供应商回调；`maxAttempts` 与超时回收 | 重试/取消/回调乱序均幂等 |
| B-06 | 成本与预算 | 每次调用记账（含失败成本）、预算阈值、超限策略、对账状态；金额用 decimal | 台账与调用记录可逐条对上 |
| B-07 | 质检 | 规则集、单集/整剧级、报告与问题项、阻断项回退映射 | 阻断项必触发退回后期 |
| B-08 | 后期与交付 | 时间线版本、分集输出、终审、交付包冻结与校验和 | 交付后版本不可覆盖 |
| B-09 | 资产与存储 | 对象存储直传、版本、校验和、授权标记、引用计数 | 资产登记→质检→正式版闭环 |
| B-10 | 组织与授权 | 部门、成员、项目授权、离职交接与回收；授权即时生效 | 停用账号同步回收授权 |
| B-11 | 通知与审计 | 通知 link 跳转、已读状态、同对象合并；审计只追加不可改 | 每条通知可定位处理页 |
| B-12 | 运维接口 | 健康检查、队列深度、日志查询、备份触发与结果 | 运维页 5 个数据块全部真实返回 |
