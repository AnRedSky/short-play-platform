# 生产质量门禁与返工规范

## 检查层级
1. 技术质量：文件存在、checksum、可解码、时长、分辨率、画幅、帧率、视频/音频流和编码。
2. 内容质量：镜头合同中的角色、场景、动作、对白、情绪和构图是否满足。
3. 连续性质量：角色外观/服装、场景、道具状态、空间位置和动作衔接。
4. 交付质量：时间线完整、字幕同步、音量、片长、黑帧/静音异常和 MP4 可播放性。
5. 合规质量：项目授权、素材来源、数据外发策略、内容审核和授权状态。

## 结果
PASS：满足自动门槛；REVIEW_REQUIRED：需人工审核；FAIL：阻断下游；WAIVED：有权限审核人基于记录原因豁免，写入审计记录。

## 质量记录
保存对象/版本、规则版本、检测时间、检测器版本、结果、问题列表、严重级别、证据引用、审核人和处置。检测器输出不得覆盖人工结论。

## 返工
FAIL 或审核拒绝时创建返工任务，定位到具体 Shot/Asset/TimelineClip；保留旧版本和失败原因；修改合同/资产后创建新版本；只重跑受影响节点；新结果重新过门禁。禁止清空历史或对整集无差别重跑。

## 人工审核
记录审核人、时间、结论、意见、关联版本和权限。高风险内容、关键连续性和最终成片必须人工审核。审核通过锁定具体版本，不锁定可变指针。

## 验收
每种质量结果可测试；FAIL 阻断后续；WAIVED 有权限和理由；返工可定位且保留历史；成片导出通过技术检查。
