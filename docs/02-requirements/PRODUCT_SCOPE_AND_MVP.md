# 产品范围与 MVP 需求

## 1. 端到端生产闭环

创意策划 → 故事设定 → 剧本/分集 → 角色/场景/道具 → 分镜 → 图片生成 → 视频生成 → TTS/音效/字幕 → FFmpeg 合成 → 人工审核 → MP4 导出。

## 2. 功能模块清单

| 模块 | 核心能力 | 优先级 |
|---|---|---|
| 企业身份与权限 | 用户、组织/部门、角色权限、项目成员 | P0 |
| 项目与剧集 | 项目、剧集、成员、项目统计 | P0 |
| 故事与剧本 | 故事圣经、剧本、对白、版本、审核 | P0 |
| 角色/场景/道具 | 设定、参考图、版本和关联 | P0 |
| 分镜 | 分镜表、镜头、提示词、镜头版本 | P0 |
| AI Provider | Mock 文本/图片/视频/TTS、外部 Provider 接口 | P0 |
| 工作流/任务 | 状态机、异步执行、重试、取消、恢复 | P0 |
| 素材资产 | 上传、元数据、预览、下载、关联 | P0 |
| 视频合成 | FFmpeg 拼接、音轨、字幕、转码、导出 | P0 |
| 模型管理 | Provider、模型、凭据、能力、用量 | P1 |
| 审核与审计 | 内容审核节点、审计查询 | P1 |
| 内部插件管理 | 元数据、启停、配置、健康检查 | P2 |
| 高级剪辑 | 多轨编辑、复杂特效、协同时间线 | P2 |

## 3. MVP 验收闭环

必须能够：
- 管理员创建用户并分配角色；项目成员仅能访问被授权项目。
- 创建项目、剧集、故事设定和剧本版本。
- 创建角色、场景、道具和分镜镜头。
- 使用 Mock Provider 生成结构化文本/图片/视频/音频占位结果，并持久化任务状态与结果。
- 支持任务进度查询、失败重试、取消和幂等保护。
- 将素材关联到分镜/剧集，使用 FFmpeg 合成至少一个可播放 MP4。
- 人工审核生产关键节点，记录审核人、时间、意见和状态。
- Docker 环境可部署；重启 API/Worker 后任务状态和资产记录不丢失。

## 4. 核心业务流程与状态

建议统一状态词汇：
- 业务对象：draft、in_review、approved、rejected、archived。
- 异步任务：pending、queued、running、succeeded、failed、cancel_requested、cancelled、retry_wait。
- 工作流运行：created、running、paused、succeeded、failed、cancelled。
- 节点：pending、ready、running、waiting_review、succeeded、failed、skipped、cancelled。

状态迁移必须由领域服务执行，禁止接口层任意赋值。终态不可直接回退；重新执行创建新运行或新尝试并保留历史。

## 5. 非功能要求

- 安全：RBAC、项目授权、密钥加密、审计、数据外发策略。
- 可靠性：幂等、超时、有限重试、死信/失败队列、Worker 崩溃恢复。
- 可观测：结构化日志、关联 ID、任务耗时、Provider 错误率和用量。
- 可维护：类型标注、自动格式化、静态检查、自动化测试、Alembic。
- 性能：分页查询、异步生成、文件流式上传/下载、合理并发限制。
- 可部署：Docker Compose、环境配置分离、备份恢复和升级回滚文档。

## 6. MVP 暂不承诺

不承诺特定模型供应商的生成质量、模型 API 永久在线、实时多人协同剪辑、自动生成即可商用、零人工审核或任意插件安全执行。供应商能力、区域、速率限制和计费由具体 API 合同决定。
