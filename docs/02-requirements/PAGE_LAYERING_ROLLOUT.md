# 短剧制作工作台分层交互改造实施规划

> 状态：已批准「混合分层」方案，进入分批实施。  
> 基线：`develop@5f180c9`；本文只规划现有 56 条业务路由，不新增页面、不改已有路径、不做全量目录重构。  
> 关联规范：`docs/02-requirements/FEATURE_INTERACTION_SPEC.md`。

## 1. 改造边界与判定口径

### 1.1 分层定义

| 层级 | 载体 | 适用对象 | 默认行为 |
|---|---|---|---|
| L0 | 现有全页 | 列表、流水线、时间线、剧本正文、数据大屏、批量队列 | 保留页面，不弹窗化；承担持续浏览与多对象对比 |
| L1 | 右侧抽屉 | 单对象详情、摘要、行内快捷操作 | 不遮挡列表主区域；刷新、复制链接、返回可恢复 |
| L2 | 居中弹窗 | 单对象创建/编辑、单关卡动作、参数确认 | 只承载一个任务，字段不超过约 12 个、步骤不超过 3 步 |
| L3 | 二次确认 | 不可逆、跨阶段、影响外部对象的动作 | 必须展示影响范围、对象数量和不可撤销说明 |

默认交互深度为 L0 → L1 → L2，只有不可逆动作进入 L3。超过 3 步或约 12 个字段的表单回退到全页，不塞入弹窗。跨域操作（例如从项目抽屉跳到剧本审核）退出当前弹层栈，落为目标页面。

### 1.2 统一验收口径

- 路径不变：所有路由仍使用 `web/src/router/index.ts` 中的现有 path。
- 状态完整：loading / empty / error / forbidden / unsaved 五类状态必须有明确呈现。
- 焦点可恢复：L1/L2 打开后焦点进入浮层，关闭后回到触发元素；Esc 只关闭最上层。
- 上下文不丢：打开 L1 不重置 L0 的搜索、筛选和滚动位置；刷新后可凭 URL 恢复同一对象。
- 结果可追溯：关卡动作、批量任务、交付冻结必须给出成功对象 ID 或可跳转的处理入口。
- 不以埋点冒充结论：当前无线上埋点，路径步数、耗时和转化率均为上线后的验收目标，不是已实测结果。

## 3. 首批垂直切片（本轮落地）

### 3.1 项目列表 L1 抽屉

- 入口：`/projects/list` 行点击或“详情”。
- 实现：抽屉由 URL `?panel=project&id=<项目ID>` 驱动，`panel`/`id` 不进入列表筛选状态。
- 关闭：保留当前列表搜索、筛选和滚动位置；刷新或复制链接可恢复同一项目。
- 验收：打开/关闭不触发整页重载；Esc、遮罩点击、关闭按钮三种关闭方式结果一致；关闭后焦点回到原行。

### 3.2 项目流水线关卡动作

- 入口：`/projects/workflow` 的 `allowed_actions`。
- L2：需要原因或参数的动作进入统一表单弹窗；字段错误就地提示并把焦点移到首个错误字段。
- L3：不可逆或跨阶段动作进入二次确认，展示目标状态、影响集数和不可撤销说明。
- 禁用：按钮不可用必须给出原因（无权限、上游未通过、预算阻断、状态不匹配），不能只灰掉。

### 3.3 弹层基础能力

- L1 与 L2 使用同一套遮罩层级：抽屉在下，弹窗在上；toast 永远在最上层。
- L1 打开时锁定页面滚动；关闭后恢复原滚动位置。
- L2 打开时焦点进入首个可操作字段；必填校验失败显示 `role="alert"` 并将焦点移到错误字段。
- 抽屉内已有 L2 时，Esc 只关闭 L2，不会一次关闭两层。

## 4. 流程节点校验与异常提示规范

| 节点 | 校验类型 | 规则 | 失败提示 |
|---|---|---|---|
| 项目创建 | 硬阻断 | 名称、题材、集数必填；集数 1–60 | “请填写项目名称、题材与 1–60 的集数” |
| 项目启动 | 硬阻断 | 预算 > 0；负责人属于项目成员 | “预算未设置，无法启动创意策划” |
| 创意确认 | 硬阻断 | 必须且只能选择一个方案 | “请先确认 1 个创意方案” |
| 剧本锁定 | 硬阻断 | 正文非空；版本号匹配；审核通过 | “剧本版本已变化，请重新加载后再锁定” |
| 剧本拆解 | 硬阻断 | 锁定剧本存在；场景/镜头无空值 | “镜头 12 缺少画面描述，不能进入生产” |
| 镜头计划固化 | 硬阻断 | 镜头契约完整；无循环依赖；成本估算通过 | “并行组存在循环依赖：组 A → 组 B → 组 A” |
| 视频生成 | 硬阻断 | 有效 Shot Contract；能力已接入；预算未超 100% | “预算已超 100%，新生成任务被阻断” |
| 音频合成 | 硬阻断 | 音色授权有效；台词镜头已锁定 | “音色 VO-02 授权已过期，不能提交合成” |
| 质检通过 | 硬阻断 | 必检项全部通过；无高风险项 | “仍有 2 个高风险项未关闭，不能通过” |
| 终审 | 硬阻断 | 全集体检通过；字幕/口型校验通过 | “第 8 集口型校验未通过，终审被阻断” |
| 交付冻结 | 硬阻断 + L3 | 授权齐全；校验和生成；版本未被覆盖 | “授权台账缺 1 项，交付已阻断；补齐后重试” |
| 批量操作 | 软提示 | 超过 50 个对象需二次确认 | “本次将处理 128 个镜头，预计消耗 ¥3,200，是否继续？” |
| 重试/取消 | L3 | 执行中任务取消需展示已产生成本 | “取消后已消耗 ¥420 不退，是否继续？” |

异常提示统一结构：一句结论 + 具体对象 + 下一步动作 + 可复制错误码。禁止只显示“操作失败”或堆栈。

## 5. 分批实施计划

### 第一批：基础设施 + 项目主链（本轮）

1. 路由驱动 L1 抽屉组合式函数与单测。
2. 项目列表抽屉接入；保留筛选、滚动和焦点。
3. AppDrawer 键盘、焦点、滚动锁定、aria 语义。
4. 弹层层级调整，保证 L2 可覆盖 L1、toast 不被遮挡。
5. 项目流水线关卡动作的前置条件与提示文案梳理。

退出条件：`typecheck`、`check`、`test` 通过；项目列表与流水线手动走查通过；无路由路径变更。

### 第二批：生产主链试点

范围：项目详情/生命周期、创意方案、剧本审核、导演档案、视频预览、后期终审。优先抽取可复用的 `DrawerSection`、`GateActionDialog`、`FieldError`，避免逐页复制。每页完成后按第 1.2 节验收，再进入下一域。

### 第三批：规格页与后台域迁移

范围：音频、任务、模型、成本、合规、运维、组织、通知。规格页共用 `SpecPage` 骨架，先补统一的 L1/L2 入口，再按域替换页面内局部实现。分析大屏不改造。

## 6. 体验指标与埋点口径

上线前只登记事件，不宣称提升幅度。建议事件：

- `overlay_open` / `overlay_close`：层级、对象类型、来源页面、关闭方式。
- `gate_action_blocked`：关卡、错误码、禁用原因。
- `form_validate_failed`：表单、字段、首次错误位置。
- `task_path_step`：同一任务的路由跳转次数与弹层深度。

首批目标（上线后验证，不是当前实测）：

- 项目“查看详情 → 进入流水线”由 2 次页面跳转降为 1 次。
- 开关抽屉不丢失列表筛选的比例达到 100%。
- 关卡动作被阻断时，用户能在当前页看到原因的比例达到 100%。
- 表单必填错误首次提交定位成功率 ≥ 95%。
- L1/L2 关闭后焦点恢复率 100%。

## 7. 风险与回滚

| 风险 | 触发信号 | 处置 |
|---|---|---|
| 路由 query 与页面筛选冲突 | 打开抽屉后筛选被重置 | 抽屉 query 使用保留键 `panel`/`id`，页面筛选继续用局部状态；冲突时回退为组件内状态 |
| 嵌套层级遮挡 | L2 被抽屉盖住或 toast 不可见 | 统一 z-index token，禁止页面自定义层级 |
| 焦点/滚动副作用 | 关闭抽屉后页面跳到顶部 | 同路径 query 不触发 scrollTop；关闭恢复触发元素焦点 |
| 深链恢复失败 | 刷新后抽屉空白 | 数据未加载时显示加载态；对象不存在时显示“项目不存在或已归档”并可关闭 |
| 范围膨胀 | 首批改动扩散到 10+ 页面 | 每批最多 6 个页面；超出拆批，不回滚已完成的基础设施 |
| 无障碍回归 | 键盘无法关闭或焦点落入背景 | Playwright 增加 Tab/Esc/焦点回归检查；不通过则阻断合并 |

回滚策略：基础设施与页面接入分开提交；关闭路由抽屉只需将页面 `open` 改回局部状态，不影响后端与路由表。
