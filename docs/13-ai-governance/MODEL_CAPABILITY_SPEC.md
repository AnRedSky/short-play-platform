# 模型能力注册规范

## 目的
模型配置描述可验证能力，而不只是供应商和模型名称。能力数据用于路由、参数校验、UI 控件和任务前置检查。

## 能力维度
通用：provider_id、model_id、capability_type、model_version、enabled、region、availability。
图片：文生图/图生图、参考图数量、分辨率、画幅、格式等（以供应商实际能力为准）。
视频：文生视频/图生视频、首帧/尾帧、参考图、时长范围、画幅、帧率、音频生成、异步查询/取消能力。
语音：TTS/ASR、语言、音色、采样率、格式、说话人能力。
LLM：上下文长度、结构化输出、工具调用、流式能力。
限制：最大输入/输出、并发、速率、超时和地区。
计价：计价单位、币种、价格来源、生效时间和核验时间。

## 数据可信度
能力来源于供应商文档、实测或管理员确认，并记录 source、verified_at 和 confidence。未知字段保持 unknown，不得猜测或硬编码虚假价格/限制。

## 路由
先按能力和输入兼容性过滤，再应用项目外发策略、区域/合同、预算、可用性和管理员优先级。fallback 不得跨越策略边界。UI 只展示模型明确支持的参数。

## 验收
不兼容参数提交前被拒绝；未知能力不推断为支持；模型能力变更可审计；路由决策可解释并追踪到配置版本。

## 2026-11-18 Provider 默认配置补充

Mork 是 MVP 默认 Provider Adapter。能力数据只在供应商文档、受控实测或管理员确认后标记 enabled；未知参数必须保持 unknown。无 Mork 凭据时返回 PROVIDER_NOT_CONFIGURED，不能以 Mock 能力或假数据冒充可用模型。Mock 仅用于 CI/显式演示。Provider/模型配置变更必须版本化并审计。
