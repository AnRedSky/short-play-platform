# 短剧单集制作流程基线 V1（E0–E7）

> 版本：V1  
> 日期：2026-11-27  
> 状态：待评审  
> 依赖：`docs/06-workflow/SHORT_DRAMA_PROJECT_FLOW_V1.md`  
> 基线：AI 生成短剧 / 24 集 / 每集 90 秒 / 4 批 × 6 集 / 分批交付

本文把项目层 P0–P7 继续下沉到单集层，定义每一集从输入确认到终审入库的完整闭环。单集是用户的主要交互与执行单位；批次只做治理、资产基线、模型版本和交付控制，不替代单集制作。

---

## 0. 整体任务规范

### 0.1 任务目标

建立可执行、可验收、可复用的单集制作流程，明确：

- 一集从哪开始、经过哪些阶段、到哪里结束；
- 每个阶段的输入、输出、门禁、退回和责任人；
- 单集状态如何推进，返工和阻塞如何表达；
- 制作中换模型、重新生成如何记录和重检；
- 单集工作区需要哪些功能，哪些动作走弹窗，哪些留在工作区。

### 0.2 范围

本版覆盖：

- E0–E7 八个单集阶段；
- 单集状态机与返工/阻塞规则；
- 镜头级、单集级、批次级模型变更在单集内的处理；
- 单集工作区功能清单与交互边界；
- 单集流程与 P0–P7、现有 9 段页面的映射。

本版不覆盖：

- 页面组件、API、数据库表的最终实现；
- 真实模型供应商对比与报价；
- 完整 NLE 剪辑器、专业混音台的功能细节；
- 3 集试跑数据和成本核算。

### 0.3 交付物

1. E0–E7 单集流程总图；
2. 8 张单集阶段设计卡；
3. 单集状态机与状态迁移表；
4. 模型变更与重新生成规则；
5. 单集工作区功能清单与交互边界；
6. 与项目层、9 段页面的映射。

### 0.4 验收标准

- 每个阶段只有一个主交付物；
- 每个门禁都有可检查的证据与签字人；
- 每个不通过场景都能定位退回阶段；
- 单集可从 E0 走到 E7，不依赖人工跳页；
- 换模型不会静默覆盖旧素材；
- 单集工作区以当前集为中心，不要求一次操作多集；
- 所有单集状态变化都能被批次看板汇总。

### 0.5 默认假设

- 单集时长 90 秒，允许平台规格内的上下浮动；
- 制作形态以 AI 生成为主，镜头契约包含模型与生成配置；
- 单集允许串行生产，也允许产能允许时并行；
- 模型可以在制作中更换，但必须走变更记录；
- 已交付集不自动重制，重制另开批次；
- 轻量动作走居中弹窗，长文本编辑与时间线留在工作区内。

### 0.6 后续输出格式

后续每次推进任务，固定输出：

1. **整体任务规划**：目标、范围、交付物、验收标准；
2. **当前完成情况**：已完成、未完成、限制；
3. **后续推进计划**：下一步动作、输入、输出、决策点。

## 1. 单集流程位置

### 1.1 单集是内层闭环

```text
项目层：P0 → P1 → P2 → P3 → P4（批次循环）→ P5 → P6 → P7
单集层：                 E0 → E1 → E2 → E3 → E4 → E5 → E6 → E7
镜头层：                              └─ 生成/审片/重试/换模型 ─┘
```

对应关系：

- P2 剧本阶段 → 单集 E0 输入确认、E1 剧本锁定；
- P3 预演阶段 → 单集 E2 镜头/资产锁定；
- P4 生产阶段 → 单集 E3 素材生产；
- P5 后期阶段 → 单集 E4 剪辑、E5 声音字幕；
- P6 质检阶段 → 单集 E6 QC；
- P7 交付阶段 → 单集 E7 终审入库。

### 1.2 单集流程总图

```text
E0 输入确认
  ↓
E1 剧本锁定
  ↓
E2 镜头与资产锁定
  ↓
E3 素材生产（生成 → 审片 → 接受/重试/换模型 → 素材齐）
  ↓
E4 剪辑（粗剪 → 精剪 → 画面锁定）
  ↓
E5 声音与字幕（对白 → 音效/配乐 → 混音 → 字幕）
  ↓
E6 单集 QC（技术/内容/一致性/合规 → 整改复验）
  ↓
E7 终审入库（终审 → 单集交付包 → 入库）
```

返工路径：

- E1 退回剧本；
- E2 退回镜头/资产；
- E3 退回镜头重试或 E2 契约；
- E4 退回剪辑或 E3 素材；
- E5 退回声音字幕或 E4 画面；
- E6 按缺陷退回 E5/E4/E3/E2/E1；
- E7 退回 E6 或重新打包。

## 2. 单集阶段设计卡

### 2.1 E0 输入确认

- **阶段目标**：确认这一集具备启动条件，避免剧本、连续性、资产或规格缺口进入生产。
- **输入与前置**：已锁定的分集大纲、前集摘要、后集钩子、平台时长与规格、批次资产基线、合规要求。
- **主交付物**：`单集任务单`，包含集号、时长目标、必达钩子、人物/场景清单、资产需求、模型基线、负责人。
- **关键动作**：核对大纲与前后集衔接；确认时长与钩子；列人物/场景/道具需求；确认资产是否齐备；指定单集负责人；标记阻塞项。
- **硬门禁**：分集大纲已锁定；前后集连续性清楚；时长目标明确；必达人物/场景齐全；资产基线可用；无阻断级输入缺口。
- **不通过退回**：退回 P2 大纲/剧本，或 P3 资产准备。
- **责任角色**：单集制片/导演 A/R；编剧、连续性、资产 C。
- **指标**：输入确认周期、缺失输入率、返工前置拦截率。

### 2.2 E1 剧本锁定

- **阶段目标**：把分集大纲变成可拍、可生成、可审核的单集锁定剧本。
- **输入与前置**：E0 任务单、全季大纲、人物圣经、前后集摘要、平台规范。
- **主交付物**：`单集剧本锁版 v1`，包含正文、台词、场景、时长、版本记录。
- **关键动作**：定稿；桌读；检查前 3 秒钩子、30 秒冲突、结尾悬念；检查人物一致性与场景可执行性；合规审核；编剧/导演签字锁版。
- **硬门禁**：时长符合目标；钩子与节奏达标；人物与前后集一致；场景和资产可实现；合规通过；编导签字。
- **不通过退回**：退回 E1 重写；若属全季人物弧问题退回 P2 大纲。
- **责任角色**：编剧 R；剧本编辑/导演 A；合规 C。
- **指标**：剧本一次通过率、单集剧本周期、重写次数。

### 2.3 E2 镜头与资产锁定

- **阶段目标**：把锁定剧本拆成可执行的镜头契约，并锁定本集资产与模型基线。
- **输入与前置**：E1 剧本锁版、创意圣经、资产库、模型能力清单、平台技术规格。
- **主交付物**：`单集镜头契约 v1`、`单集资产清单`、`单集模型基线`。
- **关键动作**：剧本拆解；分镜；逐镜写契约；准备角色/场景/道具参考；确定音色；选择模型与参数；做 3–5 个试跑镜头；连续性检查；锁定版本。
- **硬门禁**：每个镜头都有镜头契约；角色/场景/道具参考齐全；时长、对白、画幅、运镜明确；模型与参数完整；试跑通过；资产授权无阻断。
- **不通过退回**：退回 E2 镜头/资产；对白或剧情问题退回 E1；全局资产问题退回 P3。
- **责任角色**：导演 A/R；美术/资产、生成操作、配音 R；连续性 C。
- **指标**：镜头契约完整率、试跑通过率、资产锁定周期。

### 2.4 E3 素材生产

- **阶段目标**：按镜头契约生产本集所有可用素材，形成单集素材包。
- **输入与前置**：E2 镜头契约、资产清单、模型基线、产能与预算。
- **主交付物**：`镜头素材 take vN`、`单集素材包`、`生成/拍摄记录`、`返工单`。
- **关键动作**：按镜头入队；生成或拍摄；审片；接受/重试/换模型；检查角色、场景、风格一致性；整理单集素材包；标记素材齐。
- **硬门禁**：所有镜头已接受或有书面豁免；技术规格符合；角色/风格/场景一致；无阻断级缺陷；素材包完整；成本与时长在预算内。
- **不通过退回**：镜头问题退回 E3 重试；契约或资产问题退回 E2；对白/剧情问题退回 E1。
- **责任角色**：生产负责人 A/R；生成/拍摄操作 R；导演 C；QC C。
- **指标**：镜头一次通过率、重试率、单镜头成本、单集生产周期、模型切换率。

### 2.5 E4 剪辑

- **阶段目标**：把已接受素材组装成节奏成立、故事完整的画面锁定版。
- **输入与前置**：E3 单集素材包、E1 剧本、E2 镜头契约。
- **主交付物**：`剪辑时间线 vN`、`粗剪版`、`精剪版`、`画面锁定版`。
- **关键动作**：按镜头契约组装；粗剪；精剪；调节奏；处理转场；补缺镜头；检查叙事与钩子；画面锁定。
- **硬门禁**：故事完整；时长符合；钩子与结尾成立；无缺失镜头；画面锁定经导演确认；版本可追溯。
- **不通过退回**：退回 E4 重剪；素材缺失或质量不足退回 E3；剧情问题退回 E1。
- **责任角色**：剪辑师 R；导演 A；制片人 C。
- **指标**：剪辑周期、重剪率、画面锁定一次通过率。

### 2.6 E5 声音与字幕

- **阶段目标**：完成对白、音效、配乐、混音、字幕和口型对齐，形成可质检母版。
- **输入与前置**：E4 画面锁定版、E1 剧本、配音与音乐资产、平台音频规范。
- **主交付物**：`混音版`、`字幕文件`、`口型对齐记录`、`片头片尾与 credits`。
- **关键动作**：对白生成或配音；口型对齐；音效与配乐；混音；响度检查；字幕制作；时间轴校对；片头片尾与 credits。
- **硬门禁**：对白清晰完整；口型对齐；响度达标；字幕同步；无缺失台词；音乐与音效授权完整；平台规格通过。
- **不通过退回**：退回 E5 声音/字幕；画面节奏问题退回 E4；台词问题退回 E1。
- **责任角色**：声音/字幕 R；导演 A；QC C。
- **指标**：字幕缺陷率、响度合规率、音频返工次数。

### 2.7 E6 单集 QC

- **阶段目标**：在终审前完成单集全维质检，把问题拦在交付前。
- **输入与前置**：E5 单集母版、E1 剧本、E2 资产/镜头契约、模型配置、合规清单。
- **主交付物**：`单集 QC 报告`、`问题清单`、`整改记录`、`QC 通过签字`。
- **关键动作**：技术质检；内容与合规；角色/场景一致性；音频/字幕；跨集连续性；问题分级；整改复验；QC 签字。
- **硬门禁**：所有强制维度通过；无阻断级问题；整改已验证；报告完整；QC 负责人签字。
- **不通过退回**：按缺陷退回 E5 声音字幕、E4 剪辑、E3 素材、E2 资产/镜头、E1 剧本。
- **责任角色**：QC 负责人 A/R；合规 C；导演 C；后期 C。
- **指标**：单集一次通过率、缺陷逃逸率、返工成本、复验次数。

### 2.8 E7 终审入库

- **阶段目标**：完成单集终审、打包和入库，向批次和季交付交接。
- **输入与前置**：E6 QC 通过母版、元数据、字幕、权利文件、平台交付规范。
- **主交付物**：`单集终审记录`、`单集交付包`、`入库记录`。
- **关键动作**：终审；元数据整理；字幕与封面/标题检查；权利文件归档；平台规格验证；单集入库；通知批次看板。
- **硬门禁**：终审通过；交付包完整；元数据与权利齐全；平台规格通过；入库记录生成；批次状态已更新。
- **不通过退回**：QC 问题退回 E6；包内缺项退回 E7 重新打包。
- **责任角色**：制片人 A；交付制片 R；平台运营/法务 C。
- **指标**：终审一次通过率、交付包驳回率、单集按时入库率。

## 3. 单集状态机

### 3.1 主状态

```text
未开始
→ 输入就绪
→ 剧本锁定
→ 规划锁定
→ 素材生成中
→ 素材待审
→ 素材齐
→ 剪辑锁定
→ 音字锁定
→ QC 中
→ QC 通过
→ 终审入库
→ 已交付
```

侧状态：`返工中`、`阻塞`。

### 3.2 状态迁移

| 当前状态 | 触发事件 | 下一状态 | 门禁/责任人 |
|---|---|---|---|
| 未开始 | 进入批次并完成 E0 | 输入就绪 | E0 门禁 / 单集制片 |
| 输入就绪 | E1 剧本锁版 | 剧本锁定 | E1 门禁 / 编剧+导演 |
| 剧本锁定 | E2 镜头与资产锁版 | 规划锁定 | E2 门禁 / 导演 |
| 规划锁定 | 镜头任务入队 | 素材生成中 | E3 开工 / 生产负责人 |
| 素材生成中 | 镜头生成完成，待审 | 素材待审 | 生成完成 / 操作员 |
| 素材待审 | 所有镜头接受或豁免 | 素材齐 | E3 门禁 / 导演+生产 |
| 素材齐 | 画面锁定 | 剪辑锁定 | E4 门禁 / 导演 |
| 剪辑锁定 | 声音字幕锁定 | 音字锁定 | E5 门禁 / 导演 |
| 音字锁定 | 提交 QC | QC 中 | E6 开工 / QC |
| QC 中 | QC 全维通过 | QC 通过 | E6 门禁 / QC 负责人 |
| QC 通过 | 终审通过并打包 | 终审入库 | E7 门禁 / 制片人 |
| 终审入库 | 交付包被平台接受 | 已交付 | E7 交付 / 交付制片 |

### 3.3 返工与阻塞

- `返工中`：记录来源阶段、问题类型、责任人和目标阶段；修复后回到被退回阶段的门禁。
- `阻塞`：记录阻塞原因、影响范围、解除条件；阻塞不吞掉原状态，解除后回到原状态。
- 任何状态不得跳过 E1/E2/E6；E7 必须以 E6 通过为前提。
- 批次看板只汇总状态，不直接改单集状态。

## 4. 模型变更与重新生成

### 4.1 三级变更

| 级别 | 触发 | 影响 | 审批 | 重检 |
|---|---|---|---|---|
| L1 镜头级 | 同模型重试、改 seed/参数 | 单镜头 | 生成操作 + 导演抽检 | 该镜头 |
| L2 单集级 | 单集换模型或换风格 | 整集 | 生产负责人 + 导演 | 相关镜头 + E6 单集 QC |
| L3 批次/季级 | 全局换模型/视觉基线 | 批次或全季 | 制片人 + 创意总监 | 试点集 + 批次抽检 |

### 4.2 E3 内的生成循环

```text
镜头入队 → 生成 → 审片
→ 接受：写入素材包，标记 take accepted
→ 重试：同模型新 take，保留旧版本
→ 换模型：开变更单，更新模型基线，重跑受影响镜头
→ 返工：记录问题，回到对应门禁
```

### 4.3 规则

1. 每个 take 保留模型、版本、seed、参考资产、参数、成本、耗时。
2. 旧 take 不覆盖，接受版本必须有 `accepted=true`。
3. 单集换模型前先做 3–5 个镜头试跑；试跑不通过不得整集切换。
4. 换模型后重跑角色一致性、风格、技术规格、音频/口型检查。
5. 批次级换模型在批次边界决策，不在批次中途静默切换。
6. 已交付集不自动重制；重制另开“重制批次”，记录原因和范围。
7. 同一集多次镜头级切换，升级为单集级变更；跨多集出现，升级为批次级变更。

### 4.4 变更记录

- `changeId`、`scope`、`reason`；
- `oldModel` / `newModel`；
- `affectedShots`；
- `pilotResult`；
- `approver`；
- `qcResult`；
- `effectiveBatch`。

## 5. 单集工作区功能清单

### 5.1 信息架构

单集工作区固定为同一套壳，内容随 E0–E7 切换：

- 顶部：集号、集名、所属批次、时长、状态、负责人、模型基线；
- 状态条：E0–E7 阶段步进；
- 主区：当前阶段的工作面板；
- 右栏：阻塞项、变更记录、评论、版本与交接；
- 底部：当前门禁、下一步按钮、退回入口。

### 5.2 各阶段功能

| 阶段 | 工作区功能 |
|---|---|

### 5.3 交互边界

- 从单集工作区发起的轻量动作使用居中弹窗，不跳转新页面；
- 长文本编辑、镜头表、时间线保留在工作区内，不强行塞进弹窗；
- 批次页只展示集列表、状态、资产锁、模型版本和抽检结果；
- 点击某一集进入单集工作区，不要求用户在批次页批量编辑；
- 退回、换模型、重制等有影响的动作必须二次确认并记录原因；
- 已交付集显示只读状态，重制入口单独标识。

| 项目阶段 | 单集阶段 | 现有页面 |
|---|---|---|
| P2 剧本开发 | E0、E1 | 剧本创作 |

页面方向：

- 9 段顶部阶段轨继续表示项目治理节点；
- 每个阶段工作区提供批次分组和单集入口；
- 单集工作区以当前集为中心，E0–E7 状态步进；
- 项目概览看批次与风险，不进入单集细节；
- P4–P6 是循环区，进度按批次和单集汇总，不按全季一次性完成。

## 9. 风险与待确认

- 平台是否允许逐集上线，还是必须按 6 集包交付；
- 团队是否具备独立 QC 与合规签字角色；
- 模型切换带来的风格漂移是否可接受；
- 轻量剪辑能力是否足够，还是需要外部 NLE；
- 单集工作区是否承载完整时间线，还是只做镜头序列与版本管理。
