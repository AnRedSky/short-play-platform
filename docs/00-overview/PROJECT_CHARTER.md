# 项目章程

## 愿景
建设企业内部可控、可审计、可持续演进的 AI 短剧生产平台，覆盖创作资产、镜头生产、AI 任务、人工审核、媒体合成和交付。

## 目标
- 完成从创意到 MP4 的可追踪生产闭环。
- 以 Project、Episode、Shot 管理协作、生产和返工。
- 统一接入第三方模型 API，支持 Mock 和可替换 Provider。
- 生成任务持久化、异步、幂等、可重试、可取消和可恢复。
- 企业内部存储与 FFmpeg 媒体处理。
- 企业组织、RBAC、项目授权、审计和运营统计。
- Linux + Docker Compose 私有化部署，具备备份恢复能力。

## 非目标
非 SaaS、多租户计费、本地模型推理、公开插件市场、早期微服务/Kubernetes、专业级 NLE 和无人审核自动商用。

## 用户
系统管理员、组织管理员、项目负责人/制片人、编剧/策划、美术/分镜、视频制作人员、审核人员。

## 成功标准
用户可以在授权项目中创建剧集、剧本、角色、场景、道具和镜头；使用 Mock/真实 Provider 生成素材；审核后编排时间线；通过 FFmpeg 输出可播放 MP4；任务、素材、版本、成本和审核记录可追溯；系统可在企业 Linux 环境部署和恢复。

## 关键约束
外部模型调用必须经过 Provider 和数据外发策略；项目权限由服务端强制校验；凭据加密和脱敏；文件与元数据分离；状态持久化；迁移由 Alembic 管理；不得把设计状态描述为实现状态。
