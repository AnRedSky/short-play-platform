# 长夜制作台 · V4 静态交互原型

面向 AI 短剧生产的单入口交互原型：从小说改编、故事设定、分集与剧本，到资产、分镜、生成任务、质检、时间线和最终交付，完整跑通一条 12 集竖屏短剧的制作链路。

- 技术栈：原生 HTML + CSS + JavaScript，无框架、无第三方库、无构建步骤。
- 架构：`index.html` 单入口 + Hash 路由 + 按业务域拆分的页面模块。
- 状态：纯内存态。所有演示数据在页面加载时深拷贝生成，刷新即恢复初始值，不使用 `localStorage` / `sessionStorage`。
- 运行要求：必须通过 HTTP 静态服务访问，不要直接双击 `index.html`（`file://` 不属于规范支持路径）。

## 启动

Windows PowerShell：

```powershell
cd prototype\v4
.\start.ps1
```

macOS / Linux：

```bash
cd prototype/v4
./start.sh
```

默认地址：<http://127.0.0.1:4173/index.html>

可选参数：

```powershell
.\start.ps1 -Port 8080        # 指定端口
.\start.ps1 -NoBrowser        # 不自动打开浏览器
```

```bash
./start.sh 8080               # 指定端口
```

启动脚本优先使用 Python 的 `http.server`，没有 Python 时回退到 `serve.js`（Node 内置 `http` 模块，零依赖）。也可以使用任意静态服务器托管本目录，例如：

```bash
python -m http.server 4173 --bind 127.0.0.1
```

## 页面与路由

所有页面共享同一套侧栏、顶栏、身份切换和全局搜索。路由格式为 `#/<模块>/<页面>?<参数>`。

| 路由 | 页面 | 访问权限 | 主要内容 |
| --- | --- | --- | --- |
| `#/overview/dashboard` | 工作台 | 所有身份 | 今日待办、项目卡、生产动态、8 阶段流水线、新建短剧 |
| `#/overview/project` | 项目总览 | `project:read` | 项目横幅、EP01 进度、12 集季卡、成员、动态 |
| `#/story/bible` | 故事圣经 | `story:read` | 人物 / 场景 / 道具 / 服装 / 关系图，版本与一致性检查 |
| `#/story/import` | 小说改编 | `story:write` | 4 步导入向导：源文 → 章节边界 → 实体确认 → 生成计划 |
| `#/production/episodes` | 分集与剧本 | `script:read` | 12 集季卡、状态筛选、批量生成、章节映射、重新分集 |
| `#/production/script?ep=01` | 剧本编辑 | `script:read` | 三栏剧本工作台、场次导航、正文编辑、引用检查、版本记录 |
| `#/production/assets` | 资产库 | `asset:read` | 角色 / 场景 / 道具 / 服装参考，锁定、生成、一致性检查 |
| `#/production/storyboard` | 分镜台 | `board:read` | 12 镜头 9:16 画幅、Shot Contract、候选生成、送审 |
| `#/review/tasks` | AI 任务中心 | `task:read` | 队列、运行进度、失败诊断、重试、取消、新建任务 |
| `#/review/qa` | 质检与审核 | `qa:read` | 9:16 播放器、5 项检查、批注、通过 / 退回 / 重新质检 |
| `#/review/timeline` | 剪辑时间线 | `timeline:read` | 4 轨 18 片段、字幕编辑、缩放拖动、版本保存、导出前检查 |
| `#/delivery/export` | 导出交付 | `export:read` | 审核 gate、4 种规格、导出设置、逐阶段进度、历史与下载 |
| `#/system/team` | 团队与权限 | `team:manage` | 成员卡、邀请、角色调整、权限矩阵、审计日志 |
| `#/system/settings` | 模型与用量 | `settings:manage` | 项目信息、模型接入、预算、通知、演示数据、危险操作 |

未匹配路由显示 404；已登录但无当前路由权限时显示 403，并提供返回工作台入口。

## 演示身份

顶栏右侧的下拉框可在 6 个身份间切换。切换会即时重绘侧栏、页面和按钮，不需要刷新。

| 身份 | 角色 | 可见业务范围 | 关键可写操作 |
| --- | --- | --- | --- |
| 陈默 | 项目所有者 | 全部 14 个路由 | 全部操作，含团队与设置 |
| 苏禾 | 导演 | 总览、故事、分集剧本、资产、分镜、任务、质检、时间线、导出 | 剧本 / 设定 / 资产 / 分镜写入，质检终审，时间线与导出 |
| 顾青 | 编剧 | 总览、故事、分集剧本、资产（只读）、分镜（只读）、任务、质检 | 故事设定、导入、剧本编辑与版本 |
| 白露 | 美术指导 | 总览、故事圣经（只读）、资产、分镜、任务、质检 | 资产与分镜写入、生成任务 |
| 程野 | 剪辑师 | 总览、资产（只读）、分镜（只读）、任务、质检、时间线、导出 | 时间线编辑与版本、导出任务 |
| 周可 | 审核员 | 总览、任务、质检、时间线（只读）、导出（只读） | 质检批注、通过 / 退回、重新质检 |

权限判定是三层结构：路由级（决定页面是否 403）、模块级（决定侧栏和搜索是否展示）、操作级（决定按钮显示与事件是否执行）。非所有者访问 `#/system/team` 或 `#/system/settings` 会看到 403。

## 建议演示路径

1. 在工作台查看今日待办，点「新建短剧」，分别体验「一句话原创」与「导入小说」两种模式。
2. 进入故事圣经，打开周砚的设定卡，修改描述并保存，观察版本从 `REF v3` 升为 `REF v4`、状态变为待审核。
3. 点「新增设定」添加角色或场景；点「一致性检查」查看跨模块引用冲突。
4. 进入小说改编，载入示例文本，依次完成 4 步向导，生成 12 集计划后自动跳到分集页。
5. 在分集页勾选待生成集，执行批量生成，观察逐集进度与草稿状态。
6. 打开 EP01 剧本，直接编辑某一场正文（出现「未保存」标记），保存后用「保存新版本」创建 `v7`。
7. 在资产库打开场景详情，执行锁定 / 解锁、生成新参考；在分镜台打开 Shot Contract 并送审。
8. 到 AI 任务中心重试失败任务，观察 `failed → queued`；再新建一个任务，选择能力与模型。
9. 到质检页先「退回」并填写返工原因，再「重新质检」得到 96 分，最后「通过」。
10. 进入时间线，调整片段、编辑字幕并保存版本；再进入导出页创建竖屏成片任务，查看逐阶段进度与历史下载。
11. 用所有者身份进入团队页邀请成员、调整角色；在设置页修改项目信息、测试模型、导出项目状态 JSON。

## 目录结构

```text
prototype/v4/
├── index.html                 # 唯一入口
├── start.ps1                  # Windows 启动脚本
├── start.sh                   # macOS / Linux 启动脚本
├── serve.js                   # 无依赖 Node 静态服务器（Python 不可用时回退）
├── README.md
├── assets/
│   ├── css/
│   │   ├── base.css           # 设计令牌、骨架、侧栏、顶栏、响应式
│   │   └── components.css     # 业务组件与页面级样式
│   ├── img/                   # 3 张 9:16 电影感场景图（PNG）
│   └── js/
│       ├── data.js            # DB：演示数据种子 + 深拷贝
│       ├── ui.js              # UI：无状态 HTML 片段与图标
│       └── app.js             # App：路由、权限、身份、弹层、Toast、下载
└── modules/
    ├── overview/pages.js      # 工作台、项目总览
    ├── story/pages.js         # 故事圣经、小说改编
    ├── production/pages.js    # 分集、剧本、资产、分镜
    ├── review/pages.js        # 任务、质检、时间线
    ├── delivery/pages.js      # 导出交付
    └── system/pages.js        # 团队、设置
```

加载顺序固定为 `data.js → ui.js → app.js → modules/* → App.init()`。各业务模块只注册路由，不直接操作全局骨架。

## 数据与交互说明

- 演示主项目为《长夜将明》（`NYJM-26`），12 集、9:16、30fps、交付日 2026-12-12。
- 初始规模：6 个角色、12 项制作资产（共 18 项设定）、12 个镜头、8 条 AI 任务、EP01 的 8 场剧本、4 轨 18 段时间线、4 条历史导出。
- 所有“生成 / 质检 / 导出”都是前端 `setTimeout` 模拟，不调用真实模型或 ffmpeg。
- 下载文件（审核报告、SRT、交付清单、项目状态 JSON）由浏览器端 Blob 即时生成。
- 刷新页面会丢弃所有修改，回到本 README 描述的初始状态；可在「设置 → 演示数据」主动重置。
- 工作台「项目」列表中的其他项目仅用于展示项目切换版式，不承载独立业务数据。

## 浏览器与可访问性

- 目标浏览器：Chrome / Edge / Firefox / Safari 的近两个大版本。
- 响应式断点：`1180px`、`980px`、`640px`；窄屏下侧栏变为抽屉，表格与时间线在容器内横向滚动。
- 弹层支持 `Esc` 关闭；剧本编辑器支持 `Ctrl/Cmd + S` 保存；全局搜索支持 `Ctrl/Cmd + K` 唤起与方向键选择。
- 原型以键盘可操作和清晰焦点为主要目标，未做完整 WCAG 审计。

## 静态资源版本

`index.html` 中 CSS / JS 引用统一带 `?v=4.3.x` 查询参数。修改资源后请同步提升版本号，避免浏览器缓存旧文件。
