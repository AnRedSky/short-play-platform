# 长夜制作台 · V4 静态交互原型

面向 AI 短剧生产的企业级单入口交互原型：在一条 12 集竖屏短剧的完整制作链路上，叠加企业多用户工作区所需的组织、角色、数据范围、席位、安全、审计、集成与订阅能力。

- 技术栈：原生 HTML + CSS + JavaScript，无框架、无第三方库、无构建步骤。
- 架构：`index.html` 单入口 + Hash 路由 + 按业务域拆分的页面模块；`DB / UI / App` 三层。
- 状态：纯内存态。所有演示数据在页面加载时深拷贝生成，刷新即恢复初始值，不使用 `localStorage` / `sessionStorage`。
- 运行要求：必须通过 HTTP 静态服务访问，不要直接双击 `index.html`（`file://` 不属于规范支持路径）。

## 启动

Windows PowerShell：

```powershell
cd prototype\v4
.\start.ps1
```

macOS / Linux：

```bash
cd prototype/v4
./start.sh
```

默认地址：<http://127.0.0.1:4173/index.html>

可选参数：

```powershell
.\start.ps1 -Port 8080        # 指定端口
.\start.ps1 -NoBrowser        # 不自动打开浏览器
```

```bash
./start.sh 8080               # 指定端口
```

启动脚本优先使用 Python 的 `http.server`，没有 Python 时回退到 `serve.js`（Node 内置 `http` 模块，零依赖）。也可以使用任意静态服务器托管本目录，例如：

```bash
python -m http.server 4173 --bind 127.0.0.1
```

所有页面共享同一套侧栏、顶栏、身份切换、项目切换、全局搜索和通知中心。路由格式为 `#/<模块>/<页面>?<参数>`。当前共 24 条路由，其中 22 条进入侧栏，`production/script` 由分集页进入，`system/team` 为旧链接兼容别名。

| --- | --- | --- | --- |
| `#/overview/dashboard` | 工作台 | 所有身份 | 今日待办、项目卡、生产动态、8 阶段流水线、新建短剧 |

| `#/system/audit` | 审计与合规 | `audit:read` | 对象化审计事件、分类 / 级别筛选、详情抽屉、CSV 导出 |

## 演示身份

顶栏右侧的下拉框可在 9 个身份间切换。切换会即时重绘侧栏、页面、按钮与项目范围，不需要刷新。停用身份不能进入工作区。

| 身份 | 角色 | 数据范围 | 席位 | 典型可访问范围 |
| --- | --- | --- | --- | --- |
| 陈默 | 工作区所有者 | 全组织 | 企业 | 全部 24 条路由，含订阅、账单与工作区设置 |
| 沈一 | 企业管理员 | 全组织 | 企业 | 企业概览、组织、成员、角色、安全、审计、集成、工作区 |
| 林珊 | 部门负责人 | 本部门 | 企业 | 我的权限、组织、成员、审计与制作链路，仅见商务与客户部 |
| 苏禾 | 导演 | 所属项目 | 企业 | 总览、故事、分集剧本、资产、分镜、任务、质检、时间线、导出 |
| 顾青 | 编剧 | 所属项目 | 企业 | 总览、故事设定、导入、剧本编辑与版本、任务 |
| 白露 | 美术指导 | 所属项目 | 企业 | 总览、故事圣经（只读）、资产、分镜、任务、质检 |
| 程野 | 剪辑师 | 所属项目 | 企业 | 总览、资产（只读）、分镜（只读）、任务、质检、时间线、导出 |
| 周可 | 审核员 | 所属项目 | 企业 | 总览、任务、质检、时间线（只读）、导出（只读）、审计 |
| 许知 | 外部访客 | 所属项目 | 访客 | 我的权限、项目总览与审阅内容；下载受水印与审批约束 |

权限判定为「身份 → 角色 → 数据范围」三层：
- **身份**决定当前登录成员与席位状态；
- **角色**提供权限集合（`project:read`、`member:manage`、`audit:read` 等）和数据范围（全组织 / 本部门 / 所属项目 / 仅本人）；
- **数据范围**进一步过滤项目切换器、成员列表、组织树、审计日志与全局搜索结果。

路由级权限决定 403，模块级权限决定侧栏与搜索展示，操作级权限决定按钮与事件；三者共用 `app.js` 的 `ROUTE_PERMS` 与 `App.hasPerm`。组织负责人只读本部门，跨部门数据在列表层隐藏。

## 建议演示路径

1. 在工作台查看今日待办，点「新建短剧」，分别体验「一句话原创」与「导入小说」两种模式。
2. 进入故事圣经，打开周砚的设定卡，修改描述并保存，观察版本从 `REF v3` 升为 `REF v4`、状态变为待审核。
3. 进入小说改编，载入示例文本，依次完成 4 步向导，生成 12 集计划后自动跳到分集页。
4. 打开 EP01 剧本编辑正文，保存后用「保存新版本」创建 `v7`；在资产库与分镜台完成参考生成、锁定和送审。
5. 到 AI 任务中心重试失败任务，再到质检页「退回 → 重新质检 → 通过」，最后在时间线与导出页完成版本保存和成片导出。
6. 用所有者进入「我的权限」，查看 30 项权限与 24 条路由，提交一条「申请额外权限」，观察企业概览待办增加。
7. 进入「企业概览」，批准唐宁的项目访问；再进入「组织架构」查看部门树与项目成员映射。
8. 进入「成员与席位」，邀请一名编剧、打开成员详情调整角色 / 部门 / 项目范围，并体验停用与恢复。
9. 进入「角色与权限」，选中导演角色，清空一个权限组并保存，观察角色卡人数与权限项同步变化。
10. 进入「安全与登录」，测试 SSO、同步 SCIM、保存会话策略、切换 IP 强制；在「审计与合规」筛选并导出 CSV。
11. 进入「集成与 API」新建 Key、轮换与撤销；在「订阅与账单」增购 2 席，观察席位、年费与发票同步。
12. 切换到部门负责人林珊，确认只看到商务与客户部；切换到外部访客许知，确认企业治理页返回 403。

## 目录结构

```text
prototype/v4/
├── index.html                 # 唯一入口
├── start.ps1                  # Windows 启动脚本
├── start.sh                   # macOS / Linux 启动脚本
├── serve.js                   # 无依赖 Node 静态服务器（Python 不可用时回退）
├── README.md
├── assets/
│   ├── css/
│   │   ├── base.css           # 设计令牌、骨架、侧栏、顶栏、响应式
│   │   └── components.css     # 业务组件、企业治理组件与页面级样式
│   ├── img/                   # 3 张 9:16 电影感场景图（PNG）
│   └── js/
│       ├── data.js            # DB：演示数据种子 + 深拷贝（v2 企业模型）
│       ├── ui.js              # UI：无状态 HTML 片段与图标
│       └── app.js             # App：路由、权限、身份、数据范围、弹层、审计、下载
└── modules/
    ├── overview/pages.js      # 工作台、项目总览
    ├── story/pages.js         # 故事圣经、小说改编
    ├── production/pages.js    # 分集、剧本、资产、分镜
    ├── review/pages.js        # 任务、质检、时间线
    ├── delivery/pages.js      # 导出交付
    └── system/pages.js        # 企业概览、组织、成员、角色、安全、审计、集成、账单、权限、设置
```

加载顺序固定为 `data.js → ui.js → app.js → modules/* → App.init()`。各业务模块只注册路由，不直接操作全局骨架。

## 数据与交互说明

- 演示工作区为「长夜影视」企业版：24 席、`studio.cn`、上海区域、审计保留 180 天、合同至 2027-06-30。
- 演示主项目为《长夜将明》（`NYJM-26`），12 集、9:16、30fps、交付日 2026-12-12。
- 企业初始规模：15 名成员（13 正常 / 1 待接受 / 1 停用）、9 个角色、9 个部门、9 个演示身份、20 条审计、3 条访问申请、8 个集成、4 个 API Key。
- 业务初始规模：6 个角色、12 项制作资产（共 18 项设定）、12 个镜头、8 条 AI 任务、EP01 的 8 场剧本、4 轨 18 段时间线、4 条历史导出。
- 所有“生成 / 质检 / 导出 / SSO 测试 / SCIM 同步”都是前端 `setTimeout` 模拟，不调用真实模型、身份源或 ffmpeg。
- 下载文件（审核报告、SRT、交付清单、审计 CSV、发票、项目状态 JSON）由浏览器端 Blob 即时生成。
- 邀请、角色变更、成员停用、访问审批、安全策略、API Key、席位增购等操作都会写入内存审计；刷新页面后恢复初始值。
- 刷新页面会丢弃所有修改，可在「工作区设置 → 数据与演示」或「项目设置 → 演示数据」主动重置。

## 浏览器与可访问性

- 目标浏览器：Chrome / Edge / Firefox / Safari 的近两个大版本。
- 响应式断点：`1180px`、`980px`、`640px`；窄屏下侧栏变为抽屉，表格、组织树与时间线在容器内横向滚动。
- 弹层支持 `Esc` 关闭；剧本编辑器支持 `Ctrl/Cmd + S` 保存；全局搜索支持 `Ctrl/Cmd + K` 唤起与方向键选择。
- 原型以键盘可操作和清晰焦点为主要目标，未做完整 WCAG 审计。

## 静态资源版本

`index.html` 中 CSS / JS 引用统一带 `?v=4.4.0` 查询参数。修改资源后请同步提升版本号，避免浏览器缓存旧文件。
