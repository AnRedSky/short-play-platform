# 长夜制作台 V4 · 静态产品原型

面向 AI 短剧制作团队的完整产品原型：从小说导入、故事圣经、分集剧本、资产与分镜，到 AI 生成、质检审核、时间线剪辑与导出交付。

- **技术栈**：原生 HTML + CSS + JavaScript，无框架、无第三方库、无 CDN、无构建工具。
- **运行方式**：直接双击 `login.html` 或 `index.html`，主流现代浏览器（Chrome / Edge / Safari / Firefox）均可离线打开。
- **数据持久化**：浏览器 `localStorage`，键名 `sp_v4_state_v1`。刷新保留状态；可在「项目设置 → 演示数据」重置。
- **演示项目**：`长夜将明`（NYJM-26），12 集竖屏短剧，EP01《雨夜书店》。

## 快速演示路径

1. `login.html` — 预填账号 `chenmo@studio.cn` / `demo-2026`，也可跳过登录。
2. `index.html` — 工作台查看项目进度、今日待办与动态；用「新建短剧」体验两种创建模式。
3. `import.html` — 小说《长夜将明》一次导入、三次确认：章节边界 → 实体确认 → 生成分集。
4. `story.html` — 故事圣经，编辑人物 / 场景 / 道具 / 服装，查看关系图与版本。
5. `episodes.html` — 12 集季卡，批量生成剧本、查看章节映射与重分集。
6. `script.html` — EP01 八场剧本编辑器，支持脏状态、⌘S 保存、锁版与 AI 优化本场。
7. `assets.html` — 角色与资产库，生成参考、锁定版本、一致性检查。
8. `storyboard.html` — 12 个镜头的分镜台，编辑 Shot Contract、生成候选、送审。
9. `tasks.html` — AI 任务中心，队列槽位、失败诊断、重试与取消。
10. `review.html` — 9:16 模拟播放器 + QA 94 分 + 批注 + 通过 / 退回。
11. `timeline.html` — 4 轨时间线，拖动片段、缩放吸附、字幕与版本保存。
12. `export.html` — 审核通过后创建导出任务，模拟编码 / ffprobe / 解码 / checksum，下载字幕与交付清单。
13. `team.html` — 成员、角色权限矩阵、邀请与审计日志。
14. `settings.html` — 项目信息、模型接入、成本预算、通知与演示数据重置。

## 设计方向

「日光编辑部 / 电影工作室」：暖纸底、白色卡片、深石墨侧栏、朱砂主色与青绿辅助色；中文衬线标题配无衬线正文。与旧版暗色控制室风格刻意区分，强调阅读、审阅与长时间工作的舒适度。

- 主色 `#e2553d`，辅助 `#2f6f68`，纸底 `#f6f3ec`，侧栏 `#14161a`。
- 五组导航：制作 / 内容 / 协作 / 交付 / 系统，共 13 个入口。
- 通用状态覆盖：加载、空态、错误、无权限、未找到、冲突、处理中、未保存。

## 业务规则（原型内已体现）

- 项目是权限边界；成员只能访问被邀请的项目。
- 流水线：故事 → 分集 → 资产 → 分镜 → 生成 → 质检 → 时间线 → 导出。
- 只有质检 **通过** 才解锁时间线与导出；退回会锁回并生成返工任务。
- 导出冻结时间线与素材版本，经 ffprobe、完整解码与 checksum 后才发布。
- 保存产生不可变版本；导出历史永久保留。

## 已知边界（静态原型）

- 所有 AI 生成、编码、上传与 SSO 均为前端模拟，不发起真实网络请求。
- MP4 产物不包含真实视频数据；成功导出后可下载真实的 SRT 字幕或 `.txt` 交付清单。
- 账号、成员与权限仅保存在本地浏览器，不连接真实组织目录。
- 演示图片为手写 SVG 场景插画，不使用外部图片或字体 CDN。

## 重置

页面内：`settings.html → 演示数据 → 重置演示数据`。

控制台：`SP.reset()` 后刷新。
