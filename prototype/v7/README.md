# FRAMEWORK · AI 短剧生产操作系统 V7

> 从零重建的企业内部多租户 AI 短剧制作管理平台交互原型。V7 不继承 V5/V6 的页面、模块、组件、样式、演示数据或交互实现。

- **业务基准**：[`docs/完整项目业务方案（V1.0）.md`](../../docs/完整项目业务方案（V1.0）.md)
- **原型规范**：[`prototype/通用静态原型开发规范.md`](../通用静态原型开发规范.md)
- **跟踪任务**：Issue #64
- **原型版本**：V7 / From Zero
- **建议端口**：4177

## 产品模型

单一企业主体统一治理，企业内部以多个租户空间承载事业部、部门、制作中心或业务单元。租户之间默认隔离。员工通过租户成员关系进入授权空间，在个人工作台独立完成短剧制作。AI 承担专业生产执行，人工保留剧本审核、最终成片审核和必要异常决策。

平台运维、企业级管理员、租户管理员、企业审计/经营管理人员、普通员工是不同权限身份，不将编剧、导演、剪辑等专业制作岗位作为员工协作前提。

## 启动

```bash
# macOS / Linux
./start.sh

# Windows PowerShell
.\start.ps1
```

打开 `http://127.0.0.1:4177/index.html`。需要 Node.js；不支持 `file://` 直接打开。

## 演示身份

顶部身份切换用于展示菜单、路由和操作范围差异；租户切换用于展示业务上下文变化。

| 身份 | 主要可见范围 |
|---|---|
| 平台运维管理员 | 平台运行、模型治理、审计及全局演示导航；不代表默认拥有业务内容访问权 |
| 企业级管理员 | 企业租户治理、成员与角色、项目、生产、资产、交付、经营分析、审计 |
| 租户管理员 | 当前租户成员、项目、制作、资产、交付和租户范围数据 |
| 企业审计 / 经营管理 | 工作总览、授权范围项目汇总、经营分析、审计 |
| 普通员工 | 工作总览、个人项目、AI 创作、生产进度、资产、审核与交付 |

## 关键交互链路

1. 顶部切换身份与租户，观察导航和当前工作空间变化。
2. 企业管理员在租户空间创建内部租户；邀请员工进入当前租户。
3. 创建项目，进入 AI 创作助手，输入创作目标并触发演示生成状态。
4. 进入剧本审核台，查看故事大纲、分集结构和合规预检；确认正式剧本版本。
5. 进入生产调度中心，启动生产计划并查看 AI 阶段与依赖关系。
6. 进入异常处置中心，选择备用模型恢复受影响任务。
7. 查看镜头生产单元、数字资产与版本归属。
8. 在最终成片审核页完成人工终审，再进入交付中心生成演示归档状态。
9. 查看企业与员工产出分析、审计事件和模型治理页面。

## 分层实现

- `assets/js/data.js`：演示业务字典、身份、角色、租户、项目和内存状态。
- `assets/js/ui.js`：无状态渲染助手。
- `assets/js/app.js`：路由注册、应用壳层、导航、权限、内存态、弹窗和反馈。
- `modules/<domain>/pages.js`：按业务域组织页面。
- `assets/css/base.css`：设计令牌与全局基础样式。
- `assets/css/components.css`：通用组件和布局样式。

依赖方向：DB → UI → App → Modules。业务 Mock 不放在应用层，UI 不持有业务状态。

## 原型边界与未实现项

- 本原型是静态交互原型，不连接真实后端、数据库、模型 API、对象存储或媒体处理服务。
- 所有项目、成员、租户、生产任务、成本、统计与审核结果均为明确的演示数据；操作状态仅存在页面内存，刷新会重置。
- AI 生成、模型调用、视频预览、任务调度、异常恢复和交付归档均为交互流程演示，不代表真实 AI 生产能力已经接通。
- 不实现真实账号认证、服务端 RBAC、租户数据隔离、文件上传下载、真实图表计算或媒体播放。
- 页面中的预览区域是视觉示意，不提供真实视频流。
- Google Fonts、外部 CDN 和第三方运行时依赖均未使用；可离线启动。

## 业务基准说明

V7 以方案 V1.0 的核心业务定义为准：企业 → 内部租户 → 员工 → 创作项目 → 剧本版本 → 生产计划 → 镜头生产单元 → 音视频资产 → 分集成片 → 最终交付。员工独立制作；AI 执行专业生产；人工审核剧本与最终成片；企业按真实交付、质量、效率和成本进行统计。原型只演示这些业务对象和交互关系，不虚构真实生产结果。
