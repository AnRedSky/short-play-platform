# FRAMEWORK · AI 短剧生产操作系统 V7.5

> 从零重建的企业内部多租户 AI 短剧制作管理平台静态交互原型。V7 不继承 V5/V6 的页面、模块、组件、样式、演示数据或交互实现。

- **业务基准**：[`docs/完整项目业务方案（V1.0）.md`](../../docs/完整项目业务方案（V1.0）.md)
- **原型规范**：[`prototype/通用静态原型开发规范.md`](../通用静态原型开发规范.md)
- **跟踪任务**：Issue #64
- **原型版本**：V7.5 / From Zero · Flow Workspace
- **建议端口**：4177

## 产品模型

单一企业主体统一治理，企业内部以多个租户空间承载事业部、部门、制作中心或业务单元。租户之间默认隔离。员工通过租户成员关系进入授权空间，在个人工作台独立完成短剧制作。AI 承担专业生产执行，人工保留剧本审核、最终成片审核和必要异常决策。

平台运维、企业级管理员、租户管理员、企业审计/经营管理人员、普通员工是不同权限身份，不将编剧、导演、剪辑等专业制作岗位作为员工协作前提。

## 启动

```bash
# macOS / Linux
./start.sh

# Windows PowerShell
.\start.ps1
```

打开 `http://127.0.0.1:4177/index.html`。需要 Node.js；不支持 `file://` 直接打开。

## 菜单架构

侧边栏只有两个一级入口，短剧制作的全部功能收敛在“短剧制作工作台”内，按制作流程环节排序，不再把创作、生产、资产、交付拆成并列一级菜单。工作台组头不再单独占一行，侧栏从“01 总览”直接开始，品牌、工作空间卡片和组标题都不再出现。

| 一级 | 环节（二级） | 页面（三级） |
|---|---|---|
| 短剧制作工作台 | 01 总览 | `overview/home` |
| | 02 项目创建 | `workspace/projects`、`workspace/detail?id=<项目ID>` |
| | 03 剧本创作 | `studio/brief`、`studio/script-review?id=<项目ID>` |
| | 04 素材与分镜 | `pipeline/shots`、`assets/library` |
| | 05 拍摄排期 | `pipeline/schedule`、`pipeline/board`、`pipeline/tasks?id=<项目ID>`、`pipeline/exceptions` |
| | 06 后期制作 | `pipeline/post`、`pipeline/quality?id=<项目ID>` |
| | 07 审核交付 | `delivery/review?id=<项目ID>`、`delivery/center` |
| | 08 发布上线 | `delivery/release` |
| | 09 运营分析 | `analytics/enterprise`、`analytics/employee`、`analytics/me` |
| 企业与平台 | 10 企业治理 | `governance/enterprise`、`governance/tenants`、`governance/tenant-detail?id=<租户ID>`、`governance/cross-access` |
| | 11 组织与身份 | `people/members`、`people/roles` |
| | 12 平台与审计 | `platform/overview`、`platform/config`、`platform/audit`、`platform/models`、`platform/system` |

共 30 个业务路由、10 个业务域、12 个流程环节。菜单完全由路由注册表派生：模块只声明 `stage` 与 `routes`，一级/二级/三级层级与排序由 `DB.flow` 统一编排，模块不再自行拆分一级菜单。

- 制作工作台不渲染可折叠组头，12 个环节直接展开；顶部只保留全局面包屑、租户/项目/身份下拉，避免与侧栏重复。
- “企业与平台”保留折叠组头，排列在 12 个制作环节之后；管理入口较长时侧栏整体滚动，不遮挡当前页面高亮。
- 详情页统一使用 `?id=` 查询参数，`render(params)` 接收 `URLSearchParams`；`renderRoute` 与 `go()` 都会先同步项目/租户上下文，保证页面展示对象与后续操作对象一致。
- 当前工序高亮：侧栏同时标记当前环节与当前页面，便于确认所处阶段。
- 窄屏（≤768px）下侧边栏收为抽屉，由顶栏“导航”按钮开合，选择菜单项或点击遮罩后自动关闭；抽屉内 12 个环节一屏可达。
- 未匹配路由显示 404，无权访问显示 403，两者都提供“返回可用首页”入口，首页按当前身份的第一条可访问路由计算。

## 流程衔接

同一工作台内可以连续完成：创建项目 → 填写创作需求并生成剧本 → 剧本审核 → 查看素材与镜头 → 排定集次窗口 → 后期配音字幕合成 → 成片终审 → 交付归档 → 渠道上线 → 经营分析。相邻环节页面均提供进入下一步的入口，异常环节可回到异常处置，未完成前置条件时给出明确提示而不是隐藏按钮。

## V7.5 核心业务对象

V7.5 在 V7.4 流程页基础上补齐了可静态演示的企业治理与生产闭环：

- **企业主体**：唯一企业资料、企业管理员、成员/租户/项目计数、企业预算与资源策略、租户组织单元与管理员的配额表。
- **项目生命周期**：草稿、创作中、待剧本审核、生产准备中、生产中、后期制作中、质量检测中、待最终审核、已完成、已暂停、异常中、已终止；支持暂停、恢复、终止与负责人移交，移交写历史记录。
- **生产任务**：输入、输出、依赖、阶段、能力、主备模型、状态、重试次数、实际成本、失败成本、质检分；达到重试上限转异常暂停，备用模型切换保留失败成本。
- **十维质量**：剧本、合规、人物、场景、视频、表演、音频、字幕、剪辑、成片；支持复检、局部返工与质量报告导出。
- **结构化审核**：终审 9 项清单；审核记录含对象、项目、版本、审核人、时间、结果、意见、关联任务与后续处理。
- **交付与合规**：11 类交付清单、生产/质量/合规/成本四类报告；资产来源、授权依据、商业范围、到期；7 条版权与授权台账。
- **剧本影响分析**：比较 V3 与 V2 的受影响集次、场景、人物、对白、镜头、音频、时间轴与任务，确认后只重生产受影响内容。
- **经营统计**：项目数、完成率、交付集数、质量、AI 成功率、返工率、失败成本、平均周期、项目成本明细；支持手工冻结统计快照。
- **员工项目授权**：成员可加入多个租户，项目访问权与成员关系分开授予；授权弹窗按项目勾选并写审计。

## 演示身份

顶部身份切换用于展示菜单、路由和操作范围差异；租户切换用于展示业务上下文变化。

| 身份 | 主要可见范围 |
|---|---|
| 平台运维管理员 | 平台运行、模型治理、审计；不默认读取业务内容 |
| 企业级管理员 | 企业治理、成员角色、全部制作环节、经营分析与审计 |
| 租户管理员 | 当前租户成员、项目、制作、资产、交付与租户内统计 |
| 企业审计 / 经营管理 | 工作总览、授权项目、审核交付、经营分析与审计 |
| 普通员工 | 工作总览、本人项目、创作、生产、资产与审核交付 |

权限采用三层：模块声明 `permission`，应用层按 `DB.permissions[identity]` 判定，模块只渲染当前身份可执行的动作。

## 关键交互链路

1. 顶部切换身份与租户，观察导航范围与当前工作空间变化；刷新后本地演示状态保留，可在“平台与审计 → 系统运行配置”重置。
2. “项目创建”支持新建、编辑、归档、恢复、暂停、恢复生产、终止、负责人移交与 CSV 导出；列表展示项目类型、创建时间、完成/交付集数、质量状态；档案页可查看预算使用、十维质量分、任务异常、移交历史与生命周期。
3. “剧本创作”填写创作目标、受众与风格（带字数计数与必填校验），生成演示剧本；支持保存草稿、历史版本抽屉、下载、退回（原因必填 ≥10 字）与通过确认；V3 剧本页展示影响分析并可创建受影响重生产任务。
4. “素材与分镜”支持上传资产、查看详情抽屉、新增版本、下载与移除，类型筛选覆盖 11 类资产；资产以项目 ID 建立归属关系，项目改名不会断链，新版本会保留旧版本快照供追溯；资产页下方提供授权与合规台账。
5. “拍摄排期”支持新增/编辑/启动/暂停/恢复/删除排期，校验起止日期；后期页支持启动待开工环节、单环节重试与异常恢复策略；镜头单元按项目惰性生成，可单镜头重生成或批量生成；生产任务台账支持查看、重试、切换备用模型、暂停与导出。
6. “审核交付”完成 9 项终审清单勾选（未勾满不允许提交）、退回返修、集次预览、结构化审核记录、审核记录导出；交付页生成 11 类交付包并归档（二次确认、不可逆），可导出交付清单与生产/质量/合规/成本报告。
7. “发布上线”支持新增排期（渠道授权、未来时间、备注校验）、立即上线、下线、删除记录与企业渠道授权；未归档时明确提示前置条件。
8. “企业治理”支持企业主体资料与资源策略编辑、租户新增、编辑（名称/负责人/组织单元/管理员/预算/模型策略/配额/保留策略）、停用、恢复、归档，租户详情显示真实成员与项目计数；跨租户授权支持新增与撤销。
9. “组织与身份”支持成员详情、租户成员关系、项目访问授权、调整角色、重发邀请、停用/启用、移除（存在负责项目时阻断），角色详情展示权限与成员。
10. “平台与审计”支持平台运营总览、业务配置、审计类型/结果筛选、详情抽屉、CSV 导出；模型主备切换与连通性测试；手动备份、缓存清理、服务重启与演示数据重置。
11. “运营分析”支持本周/本月/本季/全部周期切换、企业/员工/个人 CSV 导出、项目成本明细、统计快照生成与历史快照表、员工产出详情。

## 交互与状态能力

- **反馈**：Toast 三列堆叠队列（成功 / 失败 / 警告 / 提示），带图标、标题与手动关闭，自动消失；危险操作使用结构化确认弹窗，展示项目、集数或影响范围。
- **表单**：必填星号、长度 / 数字区间 / 邮箱 / 日期校验，错误文案就近显示并聚焦首个错误字段，同时汇总提示错误数量。
- **加载**：异步动作统一进入按钮忙碌态（spinner + 文案）并按延迟返回结果；路由切换显示顶部进度条与页面淡入动画。
- **浮层**：模态弹窗支持遮罩关闭、关闭按钮与 Esc；详情使用右侧抽屉，支持遮罩与 Esc 关闭。
- **空态与异常**：无匹配数据展示空态行并提供清除筛选；404 与 403 均给返回入口；页面渲染异常回落到错误提示页。
- **只读态**：归档项目与归档租户进入只读，列表和详情隐藏编辑/停用/归档等写操作；即使通过 `?id=` 深链进入制作页，动作守卫也会拦截生产、上传、审核与发布操作并提示先恢复项目。
- **持久化**：项目、租户、成员、项目授权、资产、合规台账、审计、授权、排期、后期任务、渠道、发布记录、模型、交付记录、剧本版本、镜头、生产任务、质检记录、审核记录、影响分析、项目移交与统计快照写入 `localStorage`（版本不一致自动丢弃）；重置演示会清除本地键并恢复初始数据。

```

├── README.md
├── start.sh / start.ps1      # 端口 4177

│   ├── css/base.css          # 设计令牌、重置、排版工具、应用骨架、响应式
│   ├── css/components.css    # 通用组件与业务组件
```

依赖方向：`DB → UI → App → Modules`。UI 不依赖 App，DB 不依赖上层，模块只通过 `App`/`UI`/`DB` 公开接口取数。

## 样式约定

- `base.css` 只放设计令牌（颜色、间距 `--sp-1..6`、字号 `--fs-1..6`、圆角、阴影、层级、骨架尺寸）、重置、排版工具、应用骨架（shell / sidebar / topbar / page / grid）与响应式。
- `components.css` 只放可复用组件：按钮、卡片、指标、标签、表格、进度、工具栏、页签、空态、提示、图表、表单、弹窗、toast、预览区等。
- 断点四档：1100 / 900 / 768 / 480，与 `app.js` 的 `matchMedia('(max-width: 768px)')` 保持一致。

## 原型边界与未实现项

- 本原型是静态交互原型，不连接真实后端、数据库、模型 API、对象存储或媒体处理服务。
- 所有项目、成员、租户、排期、后期任务、渠道与审核结果均为明确的演示数据，统一收敛在 `data.js`；页面模块不自行编造业务数字。
- 业务操作状态写入浏览器 `localStorage`，刷新页面保留，但不跨浏览器或设备同步；菜单展开状态只存在内存。
- AI 生成、模型调用、视频预览、任务调度、异常恢复、交付归档与渠道发布均为交互流程演示，不代表真实生产能力已经接通。
- 不实现真实账号认证、服务端 RBAC、租户数据隔离、文件上传、真实下载与媒体播放；CSV 导出在前端生成。
- 页面中的预览区域是视觉示意，不提供真实视频流。
- Google Fonts、外部 CDN 和第三方运行时依赖均未使用；可离线启动。
- **未实现**：AI 自然语言生产助手、预算超限自动暂停、定时统计快照、Character/Scene/Prop/Dialogue/Timeline 独立业务对象、Shot Unit 完整字段、交付后新版本链、真实模型调度与端到端交付。
- 完整核查结论见 [`docs/V7.5-原型完成度核查与业务方案差距矩阵.md`](../../docs/V7.5-原型完成度核查与业务方案差距矩阵.md)。

## 回归结论（V7.5）

- jsdom 全路由回归：10 个业务域 / 30 条路由 / 12 个流程环节 / 5 个演示身份，失败 0，控制台错误 0，控制台警告 0。
- Playwright 交互回归：36 项检查全部通过，覆盖租户编辑、跨租户授权、项目授权、发布排期与上线、9 项终审清单与通过、模型切换、分析周期、统计快照、合规台账、侧栏导航跳转、审计 CSV 导出与 localStorage 持久化。
- 校验项：侧栏条目数与可访问路由数一致、当前环节与页面高亮正确、全 28 个代表页面可见文本无 `undefined`/`null`/`NaN`/`[object Object]` 占位、有权限页面不出现 403、无权限页面必出 403、404 视图、`?id=` 深链上下文同步、关键词与下拉筛选、终审 → 归档 → 审计链路、未完成集数禁止终审、异常恢复、撤销授权、资产新增版本与项目改名关联保持、归档项目/租户只读与深链动作拦截、归档上下文不误拦截其他项目编辑。
- 视觉回归：1440 / 430 两档无横向溢出；≤768 抽屉可开合；桌面表格操作列完整可见；侧栏 12 个制作环节一屏可达，长列表在侧栏内部滚动且不遮挡高亮项。

## 业务基准说明

V7 以方案 V1.0 的核心业务定义为准：企业 → 内部租户 → 员工 → 创作项目 → 剧本版本 → 生产计划 → 镜头生产单元 → 音视频资产 → 分集成片 → 最终交付 → 渠道上线。员工独立制作；AI 执行专业生产；人工审核剧本与最终成片；企业按真实交付、质量、效率和成本进行统计。原型只演示这些业务对象和交互关系，不虚构真实生产结果。
