# v9.3.3 导演与视频域真实项目一致性审计

审计目标：从项目流水线进入导演、视频页面后，不能再看到别的项目的人物、场景、镜头、任务与费用；空数据项目要显示真实空态，而不是借用 SP-26031 的演示内容。

## 本轮修复

### 1. 导演域四个页面按项目取数

- `director/cast`：只读取当前项目人物；档案预览取当前项目第一位人物；待处理表由真实状态与参考资产数量派生；不再固定显示“顾沉 CH-01”。
- `director/world`：场景、道具只读取当前项目；数量、卡标题、连续性表全部由真实资产生成。
- `director/shots`：镜头清单按项目过滤；集次范围由实际镜头计算；契约完整率、可提交镜头数、预算使用率、资产引用均由真实数据计算。
- `director/storyboard`：分镜卡只读取当前项目；切换项目时自动清除上一项目的集次与状态筛选，避免“切了项目却还是 E17”的假象。

### 2. 导演域动作按项目写入

- `newShot`：集次选项来自当前项目；新建 ID 按 `SH-项目号-E集-镜号` 生成，镜号在本集内递增，不再用全库镜头数拼 ID。
- `newLoc` / `newProp` / `newChar`：写入当前项目，编号按全局最大编号递增，避免跨项目覆盖。
- `batchSubmit` / `pickRegen` / `check`：只处理当前项目的镜头；一致性抽检报告写入 `project` 字段。
- `addRef` / `versionChar`：找不到指定人物时直接拒绝，不再回退到其他项目的第一位人物。

### 3. 从流水线进入下游不再丢项目

- 分集详情抽屉的“打开分镜板 / 打开视频生产”现在携带 `pid`。
- `projects.wfToShots`、`projects.wfToProduction`、`projects.wfToQuality` 按项目跳转。
- `director.plan` 的“查看镜头”携带项目，不再跳回默认项目。

### 4. 视频生产按项目投影

- `video/production` 只列当前项目的视频任务；没有任务时显示空态，不伪造生成进度。
- 批次进度按当前项目真实分集镜头通过数计算，不再固定 E16/E17/E18。
- 成本提示按当前项目任务预计/实际费用与项目预算计算。
- 队列、当前镜头、失败处理、预览入口都带当前任务或镜头，不再指向其他项目。

### 5. 生成结果改为任务台账投影

- `video/results` 的版本行由当前项目 `视频生成` 任务生成：版本号取 Attempt，结论由任务状态与质检结果映射，说明取真实失败原因或输出规格。
- 未生成任务不再显示 `v0` 或“设为采用”，避免把排队中的任务当成已有版本。
- 统计卡改为真实任务数、已采用、待复核、未采用、待生成、平均尝试数。

### 6. 顶栏项目上下文不再写死集次

- 顶栏原来固定显示“第 17 集”，进入只有 12 集的已交付项目会显示不存在的 E17。
- 现在按当前项目状态投影：制作中显示“首个未通过集 / 共 N 集”；已交付显示“已交付 · 共 N 集”；已归档显示“已归档 · 共 N 集”；URL 带 `ep` 时以 URL 为准。

### 7. 预览页与任务入口修正

- 预览页的人物、场景、对白、前后镜头均按当前镜头所属项目与集次取数。
- `video.toAttempts` 与任务抽屉的“查看尝试记录”原来跳到不存在的 `tasks/detail`，已改为真实路由 `tasks/attempt`，并携带任务 ID 作为筛选条件。

## 实测

- `director/cast?id=SP-26019`：显示沈砚、苏晚、周伯 3 人，无 SP-26031 人物。
- `director/world?id=SP-26019`：显示 3 个场景、1 个道具。
- `director/shots?id=SP-26019`：216 个镜头、E1–E12、预算未建立。
- `director/storyboard?id=SP-26019`：216 张分镜卡，集次筛选 E1–E12。
- `video/production?id=SP-26031`：3 个当前项目视频任务，E17 批次 1/18。
- `video/production?id=SP-26028`：空态，不显示任何 SP-26031 任务。
- `video/results?id=SP-26031`：3 条任务投影，版本号与“待生成”状态一致。
- `video/preview?shot=SH-26019-E01-01`：镜头、人物、前后镜头均来自 SP-26019。
- 顶栏：`SP-26019` 显示“已交付 · 共 12 集”，`SP-26031` 显示“第 17 集 · 共 24 集”，不再出现 12 集项目跳到 E17。

4. 视频域仍保留若干被后注册覆盖的早期演示动作，功能未冲突，但同名动作需要系统清理。
