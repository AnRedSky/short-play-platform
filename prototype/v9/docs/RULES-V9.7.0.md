## audio

### §R-04 生成与校验规则（audio/dialogue）

生成与校验规则 不通过项必须重生成或明确接受 阶段 要求 不通过处理 台词来源 锁定剧本版本中的对白对象 回剧本修改，不在配音页改词 音色 绑定声音档案版本 缺失则阻断，不临时试音 情绪 按场次情绪标注 情绪不符判 REVIEW_REQUIRED 回听 ASR 与文本一致 + 音量达标 重生成或调整语气后重试

### §R-05 异常提示（audio/dialogue）

异常提示 异常需与镜头一并闭环 DL-26015-064 「别开灯。」：音量偏低，需重生成后重新回听。 音量标准 −16 LUFS ± 2 语速偏差 不超过 ±8% 情绪一致 与场次标注一致

### §R-06 口型口径（audio/subtitle）

口型口径 口型不可复用其他台词结果 对齐 按对白帧计算，不按整句估算 匹配度 低于 85% 判 需人工判断 台词变更 需重做口型，不重新配音则不允许 成本 按视频秒数计费，重做单独入账 当前项目待处理 1 条

### §R-07 静态原型说明（audio/subtitle）

静态原型说明 字幕文件与口型结果在本原型中仅以参数与状态呈现，不包含真实字幕或音频文件。

### §R-08 音色规则（audio/voice）

音色规则 音色变更需重跑受影响对白 一人一档 同一人物不得同时启用多个音色 跨集一致 全剧使用同一档案版本 语言 方言片段需在档案中登记覆盖范围 克隆授权 真人声音必须留存授权书与使用范围 停用 停用不影响已交付内容，但阻止新生成

### §R-09 成本口径（audio/voice）

成本口径 语音按生成秒数计费，失败与重试同样入账；不允许把失败成本摊入成功条目。

## cost

### §R-12 预算规则（6 条）（cost/budget）

预算规则（6 条） 规则由企业管理员配置 规则 执行方式 1 项目总预算与单集预算两级控制；单集预算之和不得超过总预算，弹性需显式声明。 2 每个任务提交前估算预计成本并做预算预检，超限则任务保持「待执行」并给出阻塞原因。 3 失败、重试与取消产生的费用必须入账，不得因无产出而丢弃记录。 4 预算接近阈值时提醒项目负责人与员工；已超限则暂停受影响任务，不做整项目静默继续。 5 已合格资产优先复用，避免重复生成；复用不重复计量。 6 重要镜头允许高质量模型，但需计入预算并保留选择理由。

### §R-13 阈值口径（cost/budget）

阈值口径 阈值可配置 提醒 70% 提醒项目负责人 预警 85% 提醒部门管理员 暂停 90% 暂停非关键任务 冻结 100% 全部暂停

### §R-14 十维成本口径（cost/ledger）

十维成本口径 统计按维度可下钻 项目成本 单集成本 单镜头成本 图像生成成本 视频生成成本 音频生成成本 后期处理成本 失败任务成本 重试成本 存储与转码成本 项目 / 单集 / 单镜头 按结构逐层汇总 能力维度 图像 / 视频 / 音频 / 后期 失败与重试 单列，不回填到成功项 存储与转码 按体积与时长计量


## director

### §R-15 档案规则（director/cast）

档案规则 档案不足即门禁不通过 一人一档 同名人物不得重复建档，跨项目可复制而非共享 版本 造型或外观变更产生新版本，旧版本保留 禁用项 必须具体可执行，例如「不得戴眼镜」而非「保持风格」 参考资产 至少 3 张，包含正脸与侧脸；不足时禁止提交生产 授权 真人形象必须有授权，AI 生成形象记录供应商条款

### §R-16 规划口径（director/plan）

规划口径 镜头是唯一生产单元：任何「重做一集」的需求都拆成具体镜头；不允许用整集重跑替代局部返工。

## ops

### §R-20 配置边界（ops/config）

配置边界 运维不等于业务权限 个人凭据域 与运维配置物理隔离，平台配置不承载任何 API Key 白名单变更 需审计；执行中任务不中断，新任务须符合新策略 企业策略 由企业管理员维护，平台不代替企业决策 审计查看 运维身份不读取业务审计明细，由审计与经营管理身份查看

### §R-21 日志边界（ops/logs）

日志边界 运维日志与业务审计分离 系统运维配置 不包含员工个人凭据，也不成为绕过企业权限的通道 业务内容 运维身份默认不读取业务内容；必要访问须授权并留痕 凭据 任何日志都不记录 API Key 明文 审计 业务操作审计在「合规与审计 / 审计日志」，与系统日志分离

### §R-22 监控口径（ops/logs）

监控口径 业务方案 §21.2 要求的可观测指标 队列积压 视频生成队列 待执行 4；语音与音乐队列 待执行 2；质量检测队列 待执行 1；合成与转码队列 待执行 6 失败率 视频生成队列 失败 1；语音与音乐队列 失败 0；质量检测队列 失败 0；合成与转码队列 失败 0 重试率 视频生成队列 重试 2；语音与音乐队列 重试 0；质量检测队列 重试 1；合成与转码队列 重试 0 供应商延迟 业务 API 42 ms；任务调度器 12 ms；媒体处理 1.2 s；对象存储 8 ms；数据库 3 ms；队列中间件 5 ms 磁盘容量 3 TB GB / 已用 1.8 TB GB

### §R-23 平台边界说明（ops/overview）

平台边界说明 运维域与业务域隔离： 当前身份仅可查看平台资源与参数，业务项目、剧本、资产内容不可见；个人 API 凭据在任何身份下都只显示脱敏元数据。运维访问业务数据须单独授权并留痕。 租户模型 不提供 SaaS 租户；部门不是隔离租户 平台用户 企业成员由企业管理员维护，平台不另建用户表 模型白名单 7 个模型档案 / 16 类能力 备份 数据库全量 + 媒体增量，每日 03:00


## orgs

### §R-24 组织边界规则（orgs/departments）

组织边界规则 部门不是独立法人、不是计费单元 归属要求 项目、任务、资产、成本与交付必须归属企业；建议同时记录所属部门 访问方式 员工通过企业成员关系与项目授权获得访问，账号本身不代表可访问全部项目 多部门参与 可归属一个主部门并按授权参与其他部门项目，每次操作须明确项目上下文 停用与归档 不得删除项目、作品与历史记录；归档后数据只读可查

### §R-25 治理边界（orgs/enterprise）

治理边界 凭据隔离是硬约束 企业与个人之间： 企业制定预算、合规与资源范围，但不得代替员工配置凭据，也不得读取任何 API Key 明文。个人凭据属于独立安全域。 企业根边界 跨企业数据不共享、不检索、不导出 个人配置归属 归属员工账号，不归属项目，不随项目移交 原型说明 企业信息为虚构主体，全部数值为虚构示例数据

### §R-26 授权规则（orgs/grants）

授权规则 成员变更写审计事件 授权主体 项目负责人或有权限的企业 / 部门管理员 生效范围 仅本项目，不授予企业级数据范围 撤销 立即失效，旧链接与旧会话不可继续访问 凭据 协作不等于共享个人凭据或模型配额 通知与待办 成员变更影响待办与通知接收对象

### §R-27 人员变动处理口径（orgs/handover）

人员变动处理口径 人员变动不导致数据丢失 场景 处理要求 员工调岗 更新部门归属与项目授权；历史执行记录保持原归属 账号停用 立即失效会话；进行中任务按策略暂停；项目与资产保留 员工离职 项目移交、待办转交、授权回收；不得删除任何历史数据 部门归并 迁移成员与项目归属，保留原部门编码与历史统计 权限调整 即时生效并写审计；被撤销授权者不能通过旧链接继续访问


## post

### §R-28 阻断提示（post/delivery）

阻断提示 阻断项不进入交付包 全部镜头质量 PASS（1 个镜头未通过）；时间线无标脏片段（无时间线）；集数完整且全部通过质检（缺集 E1、E2、E3、E4、E5、E6、E7、E8、E9、E10、E11、E12、E13、E14、E15、E16）；授权齐备（RT-02 / RT-03）

### §R-29 冻结规则（post/delivery）

冻结规则 历史版本永久可查 生成即冻结 交付包不可修改 新版本 只能新建 V2，不覆盖 V1 补交付 新增文件进新版本链 引用检查 删除资产前先查引用

### §R-30 审核结论口径（业务方案 §16.3 · 四种结论）（post/review）

审核结论口径（业务方案 §16.3 · 四种结论） 不存在「差不多通过」；任何未解决项都必须落到具体集次与镜头 结论 后续动作 通过交付 进入交付流程，生成交付包 指定镜头 / 片段返工 建立局部返工任务，仅重做指定内容 退回后期 回到后期制作，重做时间线或合成 终止交付 记录原因，取消交付，保留全部记录

### §R-31 版本规则（post/versions）

版本规则 违反即视为交付缺陷 不覆盖 同 ID 只增版本，不改历史 标脏 上游变更即标脏下游引用 回指 删除前必须查引用 冻结 交付后版本不可改


## projects

### §R-32 状态定义与进入条件（projects/lifecycle）

状态定义与进入条件 状态与业务结果分离 状态 含义 进入条件 是否可终止 草稿 已创建，未启动生产 项目保存成功 可终止 创意策划中 AI 正在生成创意方案与故事大纲 员工提交创意设定 并启动 可终止 剧本创作中 AI 正在生成或修订剧本 创意方案确认 可终止 待剧本审核 候选剧本就绪，等待人工审核 剧本生成完成且自检通过 可终止 生产准备中 剧本拆解、镜头规划与视觉资产准备 剧本审核通过并锁定正式版本 可终止 生产中 执行镜头视频与音频生成 镜头生产计划固化 可终止 后期制作中 剪辑、混音、字幕合成与分集输出 镜头与音频达到可用比例 可终止 质量检测中 执行单集级与整剧级检测 分集成片输出完成（系统自动进入） 可终止 待最终审核 成片就绪，等待人工终审 检测完成且无阻断项（系统自动进入） 可终止 已完成 终审通过，尚未交付 终审结论为通过 可退回返工 已交付 交付包生成并确认交付 交付执行完成 不可回退 已归档 交付后完成资产归档 归档动作完成 不可回退 已暂停 主动暂停，阻止新任务派发 员工或管理员执行暂停 可恢复 异常中 存在需人工处理的生产异常 重试上限、资源不可用、预算触发、合规高风险 可恢复或终止 已终止 项目终止，下游计划取消 终止动作并记录原因与确认人 终态

### §R-33 迁移规则（projects/lifecycle）

迁移规则 禁止手工改状态伪造完成数量 顺序 主流程按业务动作顺序推进，不允许跨阶段跳跃 自动进出 「质量检测中」由分集成片输出自动进入；无阻断项自动进入「待最终审核」 干涉状态 「已暂停」「异常中」可挂在任一进行中状态之上，恢复回到被挂起前状态 终止 取消尚未执行的下游计划与任务，保留已产生记录与费用 返工 「已完成」后可退回后期或生产，但必须保留原终审记录 记录 状态变更写入项目生命周期记录，含原因、操作者、时间与关联任务

### §R-34 状态机提示（projects/list）

状态机提示 详见项目生命周期页 查看状态机 主流程不允许跨阶段跳跃：例如从「剧本创作中」不可直接进入「生产中」。质量检测与待最终审核由系统自动进出，不靠人工点按钮伪造。 连续失败 重试达上限 → 转人工 → 异常中 预算触发 暂停受影响任务，不整项目静默继续 终止 取消未执行任务，保留记录与已发生费用

报告可信口径 报告进入交付包 检测项 逐项列出结论，不汇总成一句 定位 集 / 场 / 镜头 / 时间码 能力标注 写明使用的检测能力 人工结论 必须记录理由与操作者

## tasks

### §R-37 成本口径（tasks/attempt）
