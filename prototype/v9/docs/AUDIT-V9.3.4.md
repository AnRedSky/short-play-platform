# AUDIT V9.3.4 · 项目隔离与交付门禁复核

审计日期：2026-11-23  
范围：`prototype/v9` 后期交付、质量、成本、资产、视频预览  
基线：7 个项目；`SP-26031` 生产中，289 / 432 镜通过，16 / 24 集 PASS，预算 ¥9,260 / ¥18,000

## 一、本轮审查发现的问题

1. **页面带 `?id=` 却不按项目取数**
   - `video/preview?id=SP-26019` 仍显示 `SH-26031-E17-04`。
   - `quality/gates`、`quality/reports`、`quality/rework` 全库取数，顶栏是长街旧梦，内容却是雾城来信和第七码头。
   - `cost/ledger`、`cost/budget`、`cost/usage` 忽略 `?id=`，在长街旧梦页面显示其他项目预算与用量。
   - `assets/library`、`assets/usage` 同样忽略 `?id=`。
2. **交付页状态与动作不一致**
   - 已交付的 `SP-26019` 仍提示“可按流程生成交付包”，但页面没有生成按钮。
   - `SP-26031` 交付门禁未满足，9 类交付内容却全部显示“已就绪”。
   - “已完成”项目的生成按钮不区分门禁、待确认交付包与授权阻断。
3. **质量页写死案例**
   - 门禁页固定 `T-8821 / SP-26015 E09` 为阻断项，交付项目也照搬。
   - 质量报告写死 `QR-26015-E09`，结论环形图与趋势图是固定数值。
   - 返工台账固定 3 条、¥133.6，交付项目仍可“发起返工”。
4. **项目资产状态残留**
   - `SP-26019` 已交付，派生层仍把 6 个角色 / 场景算作“待确认”，门禁链路显示“6 待确认”。

## 二、已完成的改造

### 后期与交付

- `post/timeline` 改为按 `?id=` 取项目，集次、时间线、镜头条、输出命名全部跟随当前项目；表头补“时基”列，修复 8 表头对 9 单元格。
- `post.newTimeline`、`post.exportTimeline` 按当前项目写入 / 校验，不再固定 `SP-26031`。
- 已交付 / 已归档项目隐藏“新建版本”“输出成片”，只保留只读入口。
- `post/delivery` 交付内容状态按项目派生：交付完成或门禁全通过才显示“已就绪”，否则“待补”；授权项单独按授权门禁显示“已就绪 / 缺失”。
- `post/delivery` CTA 按状态分流：待确认 → 确认并冻结；已完成且门禁通过 → 生成；已完成但门禁不通过 → 处理阻断；其他状态 → 回流水线。
- 已交付项目不再提示“可生成”，改为“已交付并冻结，如需变更新建版本链”。

### 质量

- `quality/gates` 按项目计算结论、阻断报告、四级门禁链路；无阻断时显示诚实空态。
- `quality/reports` 支持 `?id=` 过滤；报告数、问题数、结论分布、趋势均来自当前范围真实报告。
- `quality/rework` 支持 `?id=` 过滤；记录数、成本、平均轮次、转人工数由台账计算；已交付 / 已归档项目隐藏“发起返工”。
- 派生层对已完成 / 已交付 / 已归档项目忽略历史“待确认”资产，门禁链路不再出现假待确认。

### 视频、成本、资产

- `video/preview` 先按 `?id=` 定项目，再由 `?shot=` 找镜头；同项目镜头条、返回结果保留项目上下文。
- `cost/ledger` 支持 `?id=` 初始筛选；无可见成本时诚实空态，不静默回全库。
- `cost/budget` 只显示当前项目预算；`SP-26019` 显示“未建立独立预算”，不再展示其他项目预算。
- `cost/usage` 按项目过滤；计量差异只在供应商 / 平台用量真实不一致时出现。
- `assets/library`、`assets/usage` 按项目过滤；不可交付资产卡由当前项目真实资产生成，移除写死的 `A-1132` 示例。
- 成本、资产、质量页间跳转保留 `id`。
