# V9.3.5 业务链路与项目上下文审计

## 本轮目标

继续把 `prototype/v9` 按真实短剧生产顺序打磨：页面必须跟随当前项目，按钮必须落到当前项目的状态、任务、门禁、成本与质检记录；不接受换一套演示数据继续展示。

## 已完成的修复

### 音频与字幕

- 删除 `modules/audio/pages.js` 中早期演示动作块，文件由 703 行降为 568 行；同名动作只保留一套真实实现，避免后注册覆盖前注册造成“看似可点、实际走旧逻辑”。
- 补齐 `audio.replaceAsset`：按素材所属项目替换，登记新授权，标记时间线标脏，并要求重新混音与复检；`audio/bgm` 的“替换”按钮恢复可用。
- `audio.rightsCheck`、`audio.disableVoice` 按项目统计受影响对白与授权，不再统计全库。
- `audio.toVoice`、`audio.toRights` 保留 `?id=`，从音频页进入声音档案或授权台账时不会丢项目。

### 资产

- 删除 `assets` 的早期重复动作，保留动态引用链路、删除阻断、新版本与登记资产。
- 资产登记表单新增归属项目，默认取当前 URL 项目；写入 `project`，不再固定 `SP-26031`。
- 引用链路抽屉改为读取当前资产的项目、版本、质检、引用数；移除写死的时间线与镜头编号。

### 合规与授权

- `compliance/rights`、`compliance/risks` 支持 `?id=`，按当前项目投影台账、阻断、到期、类型分布与风险统计。
- 移除写死的 `RT-03`、`RT-02`、`IN-0087` 卡片内容，改为从当前范围第一条阻断/到期/未闭环记录生成；没有记录时显示真实空态。
- 新增 `compliance.read` 权限，项目负责人、部门管理员、企业管理员、审计角色可只读查看项目授权与风险；编辑动作仍由 `compliance.write` 控制，避免负责人从音频页跳到授权台账时被 403 挡住。
- 新增授权记录、风险记录均带项目归属；跨项目素材替换会被拦截。
- `Store.ops.replaceRightsAsset` 不再写死《第七码头》的“码头低鸣”和 `AU-26015-BGM-03`，改为按授权对象、项目与素材名称匹配。

### 质量

- 删除质量模块的重复演示动作，保留真实检测项裁决、返工重跑、返工台账。
- 发起返工时按当前项目校验依据报告、返工对象与项目归属；跨项目报告或对象会被拦截，返工台账写入当前项目。

### 视频

- 删除视频模块重复的演示批次、暂停、失败处理、采用与重生成动作，保留真实任务执行、批次生产、任务详情与采用链路。
- 保留项目感知的预览、结果页与分镜入口，预览不会跨项目取第一个镜头。

### 后期与交付

- 删除未被页面引用的旧 `post.startReview / post.pass / post.rework / post.newDelivery`，避免固定 `SP-26031` 的旧终审与交付逻辑继续注册。
- `post.epQc`、`post.runEpQc`、`post.qcIssues`、`post.refCheck`、`post.versionChain` 改为按当前项目解析；集级质检报告按项目号生成，不再固定 `QR-26031-*`。
- `post.reviewHistory`、`post.toAssets`、`post.toEpisodes/toReview/toWorks/toDelivery` 保留当前项目上下文，避免跳转后回到 `SP-26031`。
- `post.confirmDelivery` 按交付包自己的项目更新作品状态，不再写死项目。

### 成本与任务

- 删除成本模块重复的阈值、追加预算、恢复任务旧动作；恢复受限任务按当前项目查找预算与暂停任务，不再固定 `SP-26031`。
- 删除任务模块重复的演示详情、批量重试、暂停、决策、取消与并发动作，保留真实任务执行与失败处理链路。

### 数据范围

- `SP-26019` 增加项目负责人 `u-01` 作为审核成员，使当前默认身份可以进入该已交付项目的流水线，与“项目成员可见”的权限口径一致，同时不改变项目归属。
- 项目流水线对不可见项目仍不渲染任何业务内容；可见项目才展示阶段、门禁、镜头、预算与执行记录。
