# V9.3.6 交付冻结与项目上下文审计

## 本轮目标

继续按真实短剧业务顺序审查 `prototype/v9`：页面、动作、数据范围必须跟随当前项目；已交付项目不得继续生产；无权限项目不得由 `D.projects[0]` 兜底；测试必须验证真实项目上下文，而不是依赖固定 `SP-26031`。

## 已完成的修复

### 全局项目守卫

- `App.shell()` 只在 URL 项目存在且当前身份可见时写入 `projects.wfCurrent`；不可见项目不进入顶栏上下文。
- `App.renderView()` 对任意 `?id=SP-*` 先做存在性与可见性校验：不存在显示「项目不存在」，不可见显示「项目不在可见范围」，并提供返回项目列表与切换身份入口。
- 解决 `projects/workflow`、`post/delivery` 等页面在无权限项目上各自回退到 `D.projects[0]`、把其他项目内容顶上来的问题。

### 已交付 / 已归档只读

- 视频生产：已交付项目直接进入冻结页，只保留查看项目档案、查看交付包；镜头库隐藏「设为采用」，采用、重生成、失败处理均被拦截。
- 资产库：已交付项目隐藏上传与删除检查，页面提示「项目已交付 · 资产只读」；上传、删除、新版本均校验项目归属与冻结状态。
- 时间线与集级质检：隐藏新建时间线、输出成片与执行集级质检；动作层同样拦截，成片版本不再重复输出。
- 新增动作级冻结：创作、导演、音频、后期、质量域的生产动作在已交付/已归档项目上统一拦截，并提示先新建版本链；保留查看、导出、归档等只读或收尾动作。
- 音频页在只读项目上隐藏批量生成、重生成、新建声音档案、授权复核、素材登记/替换、字幕生成、口型重做等入口。
- 作品库、版本链与版本抽屉新增「新建 V2」：只有已交付/已归档项目可执行，复制来源项目设定、集数、部门与规模建立新项目草稿，写入来源项目 id、版本号与审计，跳转新项目详情；V1 镜头、时间线、交付包不复制、不覆盖。

### 管理域旧动作层清理

- 删除 `models / notify / ops / orgs / workspace` 中与 v9.1 真实层重复注册的旧演示动作，同名动作只保留一套实现。
- `models.newProvider` 新建状态改为「待验证」，测试通过后才转「启用」；`models.test/setDefault` 允许本人配置或管理员操作，并校验配置归属。
- 账号状态统一为「停用」；`orgs.toggle` 兼容「停用 / 已停用」，`orgs.offboard` 排除停用账号。
- `orgs.grant/editGrant` 审计改走 `Store.log` 并写入项目 id，不再硬编码 `AUD-DEMO`。

### 项目上下文与跨页一致性

- 工作台按项目解析：发起返工取当前项目未通过镜头；交付门禁、成本台账跳转均带项目 id；已交付项目不能直接返工。
- 首页集卡打开视频生产时带 `pid + ep`，视频页按集选中任务，不再只设置内存 scope。
- `post/timeline` 新建集时间线与输出成片携带项目与集次；`post/works` 只列当前项目作品。
- `compliance/audit` 支持 `?id=` 按项目过滤，并用项目号、任务、资产、交付包、授权编号建立关联 token；项目负责人无全企业审计权限时，默认只看自己可见项目的日志。
- `compliance/audit` 开放给 `compliance.read`，避免负责人从项目风险页点「审计日志」被 403 挡住；全企业日志仍要求 `audit.read`。
- 授权登记、风险登记的项目下拉只列当前身份可见项目，提交时再次校验归属。

### 质量页项目化收口

- `quality/reports`、`quality/rework` 无 `?id=` 时从 `wfCurrent` 取当前项目，不再默认全库；新建项目后不会在质量页看到其他项目的报告或返工台账。
- 质量报告详情、接受现状、返工重跑等动作仍按当前项目权限与状态校验。
