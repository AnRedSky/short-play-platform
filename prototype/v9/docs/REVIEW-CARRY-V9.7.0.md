# 承载方式复核：页面跳转 / 抽屉 / 弹窗 怎么选（v9.7.0 · 2026-11-25）

问题：同一功能该"跳页"还是"弹窗"？页面内容还能不能继续优化？
证据：`tools/_audit_carry.mjs`（快照 `tools/_ia_carry.txt`）——逐条解析 325 个动作的处理体，抽出承载类型、弹窗字段数、抽屉字段数、任务步骤数、目标路由，并统计每条路由的入边。

## 一、结论

**跳页与弹窗不是二选一，是三分**：页面 / 抽屉 / 弹窗，再加"页内切换"（tab、seg、筛选）。判断依据是**上下文是否需要被带走**，而不是内容多少。

现状（325 个动作）：页面跳转 **89** · 抽屉 **46** · 弹窗 **124** · 页面内切换 **31** · 行内写入 **35** · 导出 35（`common.export` 族）。

三类错配整改前合计 15 处（7 个重弹窗 + 8 个重抽屉），**本轮全部清零**，且**没有新增任何路由**：重弹窗用"宽弹窗 + 两列网格"解决，重抽屉用"字段合并"解决。

## 二、判定树（四问，从上到下）

1. **会不会换对象 / 换阶段，或需要多记录并排对照？** → **页面跳转**（带 `query` 预选 id，落地后不回退到别的项目）。
2. **是不是只看一条记录、看完就地处置？** → **右侧抽屉**（不遮表，可连续点下一行；抽屉里只放该记录的字段 + 互斥动作）。
3. **是不是一次性提交、字段 ≤5、步骤 ≤2？** → **弹窗**；字段 6–12 → **宽弹窗**（`wide: true` + 两列网格）；字段 >12 或需跨别的数据核对 → **表单页**（唯一先例是 `projects/new`）。
4. **只是同一对象的视图变化？** → **页内切换**（`tab` / `seg` / 搜索），不跳页也不开窗。

配套四条基线：

- **C-1 弹窗**：非宽弹窗 ≤5 字段；宽弹窗 ≤12 字段且必须两列排布；步骤 >3 的表单必须走 `App.job` 面板展示进度，不在弹窗里堆步骤说明。
- **C-2 抽屉**：字段 ≤10；动作 ≤5 且必须是状态互斥（执行/取消/换模型这类同组取舍），不做两件事并存。
- **C-3 跳页**：必须带目标对象 `id`；同一语义只允许一种承载（查看=抽屉，跨页=跳转，按钮命名 `toXxx` 前缀）。
- **C-4 回程**：跳页后页面必须能一键回到来源（面包屑 + 页头返回，已由 `menuPathOf` 三级路径承担）。

## 四、页面内容还能优化什么

按"能立刻见效"排序：

1. **孤岛页 13 个（只能从菜单进入，流程里没有入口）**：`audio/bgm`、`audio/dialogue`、`director/world`、`models/config`、`ops/capabilities`、`ops/logs`、`ops/overview`、`orgs/departments`、`orgs/enterprise`、`orgs/grants`、`post/versions`、`projects/list`、`workspace/home`。其中 5 个是流程中段（bgm、dialogue、world、post/versions、ops/logs），应在相邻页补一条下钻；其余 8 个是域入口，从菜单进属正常。
2. **宽表 17 页**（列 ≥9）：按 S-02 逐页裁到 ≤9。
3. **卡 ≥6 的 10 页 / 单卡 ≥40% 的 18 页**：按 S-03、S-05 并 tab、补对侧卡。
4. **提示 ≥2 的 20 页**：按 S-04 收成页尾一条。
5. **弹窗步骤文案**：`importNovel`（5 步）、`newShot`（3 步）、`newChar`（3 步）的步骤说明在提交后由 `App.job` 承载，弹窗里不再复述。

## 六、风险

- 宽弹窗不是"页面化"：字段再多也不做路由，避免为了排版把页面数从 56 涨上去；超过 12 字段才考虑表单页。
- 抽屉字段合并不删信息，只把同源字段并到一行；`_audit_kpi` 与数据口径不受影响（本轮回归全绿可证）。
- 「跳页 + 抽屉」并存最容易变成重复入口：本轮的判据是**写操作只能在抽屉里做**，跳页页只做展示与下一步，因此 `_audit_overlap` 的"写操作跨页"仍为 0。
