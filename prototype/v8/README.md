# FRAME · 企业内部 AI 短剧制作系统 V8

V8 是依据根目录《项目业务方案.md》重新设计的静态交互原型。产品边界为**单一企业内部管理系统**，不包含 SaaS 企业入驻、多租户订阅或企业间隔离运营；员工自主配置个人 AI 模型供应商和 API 凭据，企业管理组织、项目、权限、制度和经营数据。

- 业务基准：[`项目业务方案.md`](../../项目业务方案.md)
- 原型规范：[`通用静态原型开发规范.md`](../通用静态原型开发规范.md)
- 版本：V8.0.1
- 建议端口：4188
- 技术形态：纯静态 Hash 路由 SPA、原生 JavaScript、原生 CSS、无第三方运行时依赖

## 启动

Windows PowerShell：

```powershell
.\start.ps1
```

macOS / Linux：

```bash
chmod +x start.sh
./start.sh
```

浏览器访问 `http://127.0.0.1:4188/`。需要 Node.js；不支持 `file://` 双击打开。

## 导航与路由

| 业务域 | 页面路由 | 核心流程 |
|---|---|---|
| 企业管理 | `enterprise/overview` | 企业生产总览、待办、交付和资源关注事项 |
| 组织与员工 | `people/members` | 员工目录、部门、角色、邀请与项目移交边界 |
| 项目管理 | `projects/list`、`projects/workbench` | 项目创建、项目列表、员工个人工作台 |
| 创意与剧本 | `creation/brief`、`creation/script-review` | 多种创意输入、创意方案、剧本版本和人工审核 |
| 导演与分镜 | `production/board` | 剧本结构化、集场镜头生产单元 |
| 视频与音频 | `production/generation` | 生产任务、模型能力、任务状态、失败重试 |
| 后期与交付 | `production/delivery` | 时间线、质量检查、最终成片审核和交付 |
| 个人 AI 资源 | `models/providers`、`models/usage` | 个人供应商配置、凭据脱敏、能力和调用记录 |
| 数字资产 | `assets/library` | 资产检索、版本、来源、授权和复用 |
| 经营分析 | `analytics/enterprise`、`analytics/employee` | 企业和员工的真实产出统计口径 |
| 合规与审计 | `compliance/audit` | 内容授权、个人凭据安全和审计追溯 |

## 演示身份与权限

| 身份 | 主要可见范围 |
|---|---|
| 企业管理员 | 企业总览、组织员工、项目、制作、个人资源示例、经营分析、合规审计 |
| 企业管理人员 | 企业总览、组织只读、项目只读、经营分析、合规审计 |
| 普通员工 | 个人工作台、本人项目、创意剧本、生产、资产、个人模型配置和个人调用记录 |
| 审计人员 | 企业总览、项目只读、经营分析和合规审计 |

身份切换仅用于演示菜单和路由权限差异，不是真实认证或服务端授权。原型不创建“平台超级管理员”来模拟企业内业务管理，也不设置 SaaS 租户身份。

## 交互范围

- 项目创建弹窗、表单校验、项目档案查看。
- 企业员工添加演示记录。
- 个人供应商配置添加、凭据脱敏展示、连通性测试反馈。
- 创意生成、剧本通过/退回、镜头添加、任务重试/暂停、资产新版本、导出反馈。
- 身份切换、Hash 路由、侧栏菜单、404/403 页面。
- 所有交互状态仅存页面内存；刷新后恢复种子数据是预期行为。

## 原型边界

- 所有列表、指标、图表和任务均为虚构演示数据，页面已明确标注“演示”或“样例”。
- 不连接真实后端、数据库、模型 API、供应商任务、对象存储或媒体处理服务。
- 不保存真实 API Key；示例凭据仅用于展示脱敏界面。
- 不实现真实 AI 生成、供应商调用、任务调度、文件上传下载、视频播放、费用结算和持久化。
- 不引入 Agent、智能体编排、Skill 或智能体运行时；自动化仅以业务流程、任务依赖和规则状态表达。
- 交互按钮只改变原型内存态或给出明确的演示反馈，不得据此认为生产功能已经实现。
- 项目指标和成本不代表真实经营数据；真实系统须以供应商账单、任务回执和资产校验为准。
