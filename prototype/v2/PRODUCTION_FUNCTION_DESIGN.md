# 短剧生产功能设计说明

> 版本：v2 · 2026-11-19  
> 范围：只讨论功能、交互、状态与产物，不展开授权、内容安全、平台合规等非功能议题。  
> 对应原型：`prototype-v2`（16 页静态高保真原型）。

## 一、设计基线

这套原型把短剧生产拆成一条**有输入契约、有唯一产物、有下游消费者**的流水线：

> 一句话 / 整本小说 → 章节边界 → 故事圣经 → 分集规划 → 逐集剧本 → 资产与分镜 → 画面 → 配音字幕 → 质检审核 → 时间线与交付

三条原则决定所有页面的交互：

1. **先确认、再生成。** 模型不替用户决定章节边界、人物实体、分集钩子；这三处必须人工确认后才能批量生成。
2. **产物即状态。** 每一步的结果不是 toast，而是一个可被下游引用的版本化对象（章节目录、实体 v5、分集 v3、剧本 v6、镜头合同、资产 REF、时间线 tl_v6）。
3. **失败可回退。** 失败保留 attempt 和诊断码，不覆盖已成功产物；审核退回产生返工任务，而不是直接改原片。

## 三、生产对象模型

| 对象 | 关键字段 | 产生位置 | 下游消费者 |

| Project | id、名称、集数、画幅、时长、状态 | 新建项目 | 全部页面 |
| Chapter | no、标题、页码范围、字数、正文、状态 | 章节解析 | 分集规划、剧本 |
| Entity | id、类型、名称、别名、视觉锚点、目标、限制、隐藏信息、语气、小传 | 故事圣经 | 分集、剧本、资产、分镜、画面 |
| Relation | from、verb、to | 故事圣经 | 设定检查、剧本 |
| Episode | no、标题、状态、章节来源、钩子、时长、剧本版本 | 分集规划 | 剧本、资产、时间线 |

| ShotContract | shot no、景别、运镜、时长、首尾帧、角色引用、资产引用 | 分镜 | 画面生成、审核 |
| Asset | 类型、名称、REF 版本、引用集数、锁定状态 | 资产库 | 分镜、画面、审核 |
| Dialogue | 行号、角色、文本、情绪、声线、语速 | 剧本 | 配音、字幕 |
| TimelineClip | 轨道、入点、出点、素材、转场 | 时间线 | 导出 |
| Delivery | 规格、标题、封面文案、简介、集数卡、字幕策略 | 导出 | 发布侧 |
| Task | task_id、能力、对象、模型、attempt、状态、成本、诊断 | 所有生成动作 | 任务中心、制作台 |

**引用规则：** 下游只读上游的冻结版本；修改上游必须生成新版本，旧版本保留。资产页的 REF 锁定、剧本页的“锁版”、时间线的“tl_v6”都是同一条规则的不同表现。

## 四、状态机

### 4.1 项目 / 集

| 状态 | 进入条件 | 可做的操作 | 离开条件 |
|---|---|---|---|
| `imported` | 小说已解析 | 校对章节边界、确认实体 | 边界验收 + 实体确认 |
| `planned` | 分集规划已保存 | 改章节归属、批量生成 | 至少一集剧本生成 |
| `scripting` | 有集在生成 / 草稿 | 改台词、锁版、补生成 | 全部目标集锁版 |
| `producing` | 资产 / 分镜 / 画面 / 配音推进 | 重跑失败镜头、换参考 | QA 通过 |
| `review` | 提交审核 | 批注、退回、通过 | 通过或退回 |
| `rework` | 审核退回 / 批注转返工 | 重跑、重新提交 | 返工完成 |
| `delivered` | 导出完成 | 下载、复制交付包 | — |

### 4.2 任务

`queued → running → success / failed / cancelled`。失败不自动降级模型；取消保留已产生费用；重试生成新 attempt，不覆盖旧产物。

### 4.3 审核与返工

`QA 自动检查 → 人工决定 → 通过 / 退回 → 返工任务 → 重跑 → 重新 QA`。

批注分两级：`场次` 用于整体节奏，`镜头` 用于具体画面。镜头批注的锚点固定为 `SCxx · SHOTyy`，转返工后进入任务中心，完成后回写批注状态。

## 六、逐环节功能设计

### 01 新建项目

**目标：** 把“想法”变成一个有集数、画幅、时长约束的生产项目。

- 两种入口：一句话原创、导入小说改编。切换入口只改变第一阶段输入，不改变后续链路。
- 一句话模式填一句创意，系统生成故事圣经初稿与分集钩子；小说模式进入 `import.html`，先解析再确认。
- 交互顺序：填项目名 → 选题材 / 集数 / 单集时长 / 画幅 → 创建 → 自动进入对应下一步。
- 状态反馈：创建后项目出现在项目库，状态为“制作中”，可继续制作。
- 设计理由：先锁定集数与时长，后续所有模型调用的 token、镜头数和成本才有统一分母。

### 02 章节解析与边界验收

**目标：** 把整本小说变成可被分集消费的章节数组，并让人确认“一章从哪到哪”。

- 解析产出 24 章，左侧列出编号、标题、页码范围、字数、状态；中部是原文阅读器；右侧是目标集数、单集时长、分集策略。
- 「边界校对」抽屉支持逐章 **拆分 / 并入下一章 / 撤销上一步 / 验收当前边界**。
- 拆分按段落中位数切分，标题加“上 / 下”，字数按比例拆；并入把下一章正文、字数、页码合并到当前章。
- 每次改动先快照，撤销恢复整个章节数组；验收后页头 chip 变为“章节边界已验收 N 章”，集纲与剧本才允许批量生成。
- 异常：末章不能并入下一章；拆分后新章状态标黄，需要人工确认。
- 设计理由：章节边界是分集与剧本的上游契约。边界没验收就生成，后面所有集都会跟着错。

### 03 故事圣经

**目标：** 做全季唯一的设定源，避免角色、场景、道具在多集里漂移。

- 左栏实体索引支持搜索、按人物 / 场景 / 道具筛选；中部编辑实体字段；右栏是关系图、设定检查、版本记录。
- 可编辑字段：名称、别名、身份、视觉锚点、叙事目标、冲突 / 限制、隐藏信息、语气、小传；可换参考图。
- 可新增实体、新增关系（from / verb / to）；关系进入关系图与设定检查。
- 保存写入 v5 草稿，页头 chip 与版本记录同步；重新打开可恢复。
- 设定检查给出连续性提示，例如借阅册颜色冲突、周砚左手伤在 EP07 才出现。
- 设计理由：把“人物小传”和“视觉锚点”放在同一个实体里，剧本、资产、分镜、画面都引用同一份，改名不会各页各写一套。

### 04 分集规划与章节映射

**目标：** 把章节分配到 12 集，并让每集有钩子、时长和来源。

- 季卡显示 12 集：状态、章节来源、钩子、时长、剧本版本、操作。
- 「章节映射」抽屉逐章选择归属集，实时统计已分配 / 未分配 / 改动处数；保存为分集 v3 草稿。
- 「批量生成剧本」对 9 个待生成集逐一创建任务；单集可补生成；已锁定集不重复生成。
- 状态：待生成 → 生成中 → 草稿 → 已锁定；卡片颜色与顶部季条同步。
- 异常：未分配章节、单集超过目标时长、钩子为空时给出提示。
- 设计理由：分集是“整本小说”与“单集生产”之间的唯一转换层。没有映射，批量生成无法知道每集读哪些章。

### 05 逐集剧本

**目标：** 把分集大纲写成可拍摄的场次、动作和对白。

- 左栏 8 场；中部纸张式剧本；右栏是本场 AI 建议、剧本统计、锁版操作。
- 正文可直接编辑；对白按角色与行号组织；支持新增场次、AI 优化本场、锁版。
- 顶部 12 集 chips 可切换集；未生成集只显示结构预览，编辑 / 保存 / 锁定禁用并提示回分集页生成。
- 锁版后生成剧本 v6，下游资产与分镜只读该版本。
- 异常：锁版后继续编辑必须先解锁或生成新版本；已锁定集不允许批量覆盖。
- 设计理由：剧本是资产、分镜、配音三者的共同上游。锁版把“还在改”与“可以生产”分开。

### 06 批量剧本生成

**目标：** 让“整本小说 → 12 集剧本初稿”成为一次可监控的批处理，而不是逐集手工创建。

- 入口在分集页；一次选择待生成集，系统按“分集大纲 + 故事圣经 + 章节原文”逐集调用文本模型。
- 每集有独立任务与状态；批量面板显示完成数、失败数、当前集、取消按钮。
- 完成一集即写回分集状态与剧本版本；失败保留诊断，可单集重试。
- 生成结果不是最终稿：进入 `script.html` 后仍需人工改台词、锁版。
- 设计理由：每集手动创建会中断季级节奏；批量生成把重复动作折叠，同时保留单集补生成与失败重试。

### 07 资产与一致性

**目标：** 把剧本里的“人、景、物、服装”抽成可复用、可锁定的视觉实体。

- 资产页按角色 / 场景 / 道具 / 服装筛选；卡片显示 REF 版本、引用集数、锁定状态、一致性分数。
- 点击资产打开抽屉：参考图、来源剧本、引用镜头、替换参考图、锁定 REF。
- 锁定后下游只读该版本；换参考必须生成新 REF，旧镜头不被静默替换。
- 异常：角色跨集服装变化、道具损耗、场景季节变化进入一致性检查。
- 设计理由：画面一致性不是靠提示词，而是靠“一个实体一个 REF、下游显式引用”。

### 08 分镜与 Shot Contract

**目标：** 把场次拆成可生成的镜头合同，每个镜头有明确时长、景别、运镜和引用。

- 分镜页以 24 个镜头卡呈现；可按场次 / 状态筛选；点开对比候选、查看合同字段、送审。
- 合同字段：shot no、场次、景别、运镜、时长、首尾帧、角色引用、资产引用、台词锚点。
- 送审后进入审核队列；画面生成只读已确认合同。
- 异常：合同缺角色引用、时长超过单集预算、首尾帧冲突时阻止送审。
- 设计理由：视频模型需要结构化合同，而不是一段散文；合同也是审核定位的最小单位。

### 09 画面生成

**目标：** 按合同批量生成镜头视频，失败可诊断、可改参重跑。

- 制作台第 04 步显示生成范围、画幅、单条时长、并发；右侧显示模型、计费、预计耗时、失败策略。
- 一次生成创建多个任务，逐条更新进度；失败镜头保留诊断码，不覆盖已成功产物。
- 支持改参重跑、查看产物、打开专业视图。
- 异常：角色一致性低、首尾帧不匹配、超时；不自动降级模型。
- 设计理由：视频是最贵的步骤，必须让用户看见“这次要花多少、失败会怎样”，而不是一个黑盒按钮。

### 10 配音与字幕

**目标：** 把对白变成角色声线音轨与可交付字幕。

- 左栏角色与声线；中部对白表；右侧当前行参数、情绪、语速、重录。
- 支持试听、单条重录、字幕断行、导出 SRT。
- 对白行号与剧本一致；重录只替换该行音轨，不影响其他行。
- 异常：声线未绑定、情绪标签缺失、字幕行超长。
- 设计理由：配音是“按行”生产的，不是整集一次生成；按行才能重录和定位。

### 11 质检、镜头批注与返工

**目标：** 在成片前发现画面、音画、角色、字幕问题，并把问题变成可执行返工。

- 右侧自动检查：画幅、音画同步、黑帧 / 重复帧、角色一致性、字幕断行；给出 QA 分数。
- 中部剪辑条 SC01–SC08 可点选；右侧再选 SHOT；批注锚点显示 `SC03 · SHOT 09`。
- 新增批注写入列表；每条可“转返工”，按钮变为“已转返工”，计数更新。
- 审核决定：退回重跑 / 审核通过；通过后才解锁时间线与导出。
- 返工任务写入任务中心，完成后回写批注状态（当前原型已做前端持久化，回写仍为演示）。
- 设计理由：审核意见必须能落到一个镜头，否则制作人员无法知道改哪一秒。

### 12 时间线、标题与交付

**目标：** 把画面、音轨、字幕、标题卡组装成多规格成片。

- 4 轨时间线：画面、对白、音乐、字幕；支持缩放、吸附、选中片段。
- 右侧成片预览、交付规格、版本链。
- 导出抽屉可编辑成片标题、封面文案、发布简介；多选 9:16 / 16:9 / 1:1、封面卡、集数卡、独立 SRT。
- 导出前校验标题 / 封面 / 简介非空；导出进度按所选规格生成交付包，完成卡展示规格与封面文案。
- 异常：QA 未通过时导出被锁定；规格全不选时阻止导出。
- 设计理由：交付不是“一个 MP4”，而是标题、封面、集数卡、字幕策略的组合；这些字段必须在导出前一次确认。

## 七、横向能力

### 7.1 版本与血缘

每个产物带版本号：章节边界（验收版本）、故事圣经 v5、分集 v3、剧本 v6、资产 REF v2、时间线 tl_v6。下游记录“我读了哪个版本”，上游改动生成新版本，不静默覆盖。

### 7.2 引用完整性

资产 REF、角色引用、镜头合同、对白行号、字幕行号使用稳定 ID。改名只改显示名，不改 ID；换参考生成新 REF，旧引用保留。

### 7.3 批量与单集

批量生成只处理“待生成”集；已锁定集跳过；失败集单独重试。单集补生成不改变其他集状态。

### 7.4 Gate

三类 gate：

1. 章节边界验收 → 才允许分集与批量剧本。
2. 剧本锁版 → 才允许资产、分镜、配音。
3. QA 通过 → 才允许时间线与导出。

### 7.5 失败与返工

失败保留 attempt、模型、输入快照、诊断码；重跑生成新 attempt。审核退回或镜头批注转返工进入任务中心，完成后回到原对象重新 QA。

### 8.3 仍存在的功能缺口

1. 故事圣经改字段后，没有列出受影响的集、场、镜头。
2. 章节边界只在前端内存与页面内生效，未持久化到分集映射。
3. 剧本页还不能拖拽场次、改场景头、改派对白角色。
4. 分镜页没有“按场次批量拆镜 / 镜头排序”的入口。
5. 返工任务只进入任务列表，完成后的批注回写仍是演示。
6. 导出交付包是前端清单与进度，不产生真实多文件。
7. 集数卡、封面只有字段，没有安全区预览。

## 九、验收脚本

### 9.1 小说改编主链

1. 项目库 → 新建短剧 → 导入小说改编 → 选 24 章示例。
2. 解析 → 边界校对：拆分一章、撤销、再并入一章、验收。
3. 实体确认：把“他”合并到周砚；打开故事圣经改小传、加关系、保存 v5。
4. 分集页：改一章归属、保存 v3、批量生成 9 集。
5. 打开 EP03 剧本：改一句台词、AI 本场建议、锁版。
6. 资产页：锁定一个角色 REF；分镜页：打开一个 Shot Contract 送审。
7. 制作台：生成画面，制造一个失败，改参重跑。
8. 配音页：重录一条对白；审核页：选 SC03 / SHOT 09 写批注、转返工。
9. 任务中心：看到返工任务。
10. 审核通过 → 时间线 → 填标题 / 封面 / 简介 → 勾选 9:16 + 封面卡 + 集数卡 + SRT → 导出。

### 9.2 必须覆盖的异常

- 章节边界未验收时点批量生成 → 阻止并提示。
- 未生成集直接打开剧本 → 只读结构预览，编辑禁用。
- 已锁定集再次批量生成 → 跳过，不覆盖。
- 分镜缺角色引用 → 阻止送审。
- QA 未通过直接导出 → 锁定。
- 导出标题 / 封面 / 简介为空 → 阻止。
- 规格一个都不选 → 阻止。

## 十、下一轮优先级

1. **故事圣经变更影响面**：改字段后列出受影响集、场、镜头，逐项确认。
2. **章节边界持久化**：拆分 / 并入 / 验收写入分集映射，刷新不丢。
3. **剧本结构编辑**：场次拖拽、场景头、对白角色改派、场次复制。
4. **分镜拆镜与排序**：场次批量拆镜、镜头增删、运镜 / 时长字段。
5. **返工闭环**：任务完成后回写批注与 QA，制作台同步状态。
6. **交付预览**：封面安全区、标题截断、集数卡预览。

> 一句话总结：主链的“生成”已经成立；下一步要补的是“修改之后，下游怎么知道、怎么跟着变”。
