# 制作链路功能完整性评估

> 评估日期：2026-11-19  
> 评估范围：只评估功能链路：用户要完成一条短剧生产链，需要哪些功能、现在缺哪些、下一步补什么。  
> 评估对象：`prototype-v2` 交互原型 ＋ `docs/` 现有产品基线。

## 一、结论

原型已经能把整季链路点完：

> 新建项目（一句话 / 小说）→ 24 章切分 → 实体确认与合并 → 12 集分集 → 章节映射调整 → 9 集批量剧本 → 任选一集精修锁版 → 资产 / 分镜 / 画面 / 配音 → QA / 审核 → 时间线 / 导出

按“功能可演示完整度”评估：**4.5 / 5**。  
按“真实生产可用完整度”评估：**3.0 / 5**。

差距不在页面数量，而在“编辑后的下游联动”：故事圣经改了字段，分集与剧本是否引用新版；章节边界改了，分集覆盖和镜头是否重算；镜头批注转返工后，任务状态是否回到制作台。原型已经把编辑入口补齐，下一步是打通这些状态。

## 二、导航信息架构

左侧全局导航按职责分四组，顶部只在单集页显示“单集工作区”，两者不再重复。

| 层级 | 位置 | 职责 | 项目 |
|---|---|---|---|
| 全局 | 左侧栏 | 跨项目、跨集入口 | 项目：项目库 / 项目总览；内容：分集总览 / 故事圣经 / 资产库；协作：任务中心 / 审核队列；配置：模型接入 / 成本用量 / 团队设置 |
| 单集 | 顶部条 | 当前集深视图 | 本集制作 / 剧本 / 分镜 / 配音 / 时间线 |

分集、故事圣经、资产、任务、审核、模型、成本、团队页不显示顶部单集条；只有制作台、剧本、分镜、配音、时间线显示。

## 四、这轮已经补上的功能

1. **故事圣经可编辑。** 新增 `bible.html`：人物/场景/道具 8 个实体可改名称、别名、身份、视觉锚点、目标、限制、隐藏信息、语气与小传；可新增实体、新增关系、查看关系图与设定检查，保存为 v5 草稿。
2. **章节边界可验收。** `import.html` 新增「边界校对」抽屉：逐章拆分、并入下一章、撤销上一步、整季验收；章节数与向导同步更新，验收后集纲才允许批量生成。
3. **同义实体合并。** `import.html` 可把“他 · 待消歧”合并到周砚或林未，显示 34 处引用同步更新；也可保留为独立角色。合并结果进入关系列表。
4. **章节映射可改。** `episodes.html` 新增「章节映射」抽屉，逐条选择归属集，实时显示已分配数量与改动处数，保存为分集 v3 草稿。
5. **镜头批注与返工。** `review.html` 剪辑条可点选场次，右侧可再选 SHOT；批注锚点落到“场次 · 镜头”，新增批注写入列表，每条可一键转返工任务。
6. **标题文案与集数卡。** `timeline.html` 导出抽屉可编辑成片标题、封面文案、发布简介，并勾选 9:16 / 16:9 / 1:1、封面卡、集数卡、独立 SRT；导出结果按所选规格生成交付包。
7. **导航去重。** 左侧按项目/内容/协作/配置分组，顶部只保留单集工作区；全局页不再显示重复的单集条。
8. **全站弹窗/抽屉可用。** 共享层补了 `data-open` 统一处理，各页“新增/导出/邀请/映射/边界”按钮不再只画不响应。
9. **批量与单集剧本状态同步。** 批量生成后状态写回 `sp_v2_eps`，`script.html` 的 12 集 chips 能正确区分已锁定、草稿、待生成。

## 五、仍然缺失的功能方向

### P0：影响主链能否真正完成

| 功能 | 现状 | 要补成什么 | 落点 |
|---|---|---|---|
| 编辑后的下游联动 | 故事圣经可改 v5，但分集/剧本/资产不会自动标记“引用已变化” | 实体版本号进入剧本与资产引用；改后列出受影响集、场、镜头，逐项确认 | `bible.html` → `episodes.html` |
| 覆盖与删留标记 | 只显示 24/24 覆盖 | 每章标记“采用 / 压缩 / 删除 / 新增”，统计主线、人物弧、钩子覆盖 | `episodes.html` 章节映射抽屉 |
| 剧本结构编辑 | 可改正文，不能改场次结构 | 场次拖拽排序、插入/删除、场景头、对白角色改派、场次复制 | `script.html` 场次栏 |
| 跨集资产复用 | 资产页按 EP01 口径展示 | 角色 12 集服装/状态、道具损耗、场景季节变化；按集筛选复用 | `assets.html` |
| 场次拆镜 | 已有 24 个镜头合同，但没有拆镜入口 | 按场次批量拆镜、镜头增删/排序、运镜/时长/转场字段 | `board.html` |
| 返工任务闭环 | 批注可转返工，但没有任务状态与回写 | 返工任务进入任务中心；重跑完成回写批注与 QA，制作台同步状态 | `review.html` → `tasks.html` |
| 标题与封面可预览 | 可填标题/封面/简介，但只是表单 | 封面缩略图、标题在 9:16/16:9 安全区内的预览与截断检查 | `timeline.html` 导出抽屉 |

## 七、下一轮只做四件事

1. **打通编辑后的下游联动**：故事圣经 v5 被剧本/资产引用后，改字段能列出受影响集、场、镜头。
2. **把章节映射做成覆盖验收**：在拆分/并合边界之上，加“采用 / 压缩 / 删除 / 新增”与主线、人物弧、钩子覆盖率。
3. **补剧本结构与拆镜**：场次拖拽、场景头、对白改派；按场次批量拆镜、镜头排序与运镜字段。
4. **补返工任务闭环**：批注转任务后进入任务中心，重跑完成回写批注与 QA，制作台同步状态。

这四件补完，整季从原著到多平台交付的功能链才算闭合；连续性、音乐、本地化、A/B 放到后续迭代。
