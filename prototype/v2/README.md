# 长夜制作台 · 系统原型 v2

AI 短剧生产平台的高保真静态原型。目标不是展示后台页面数量，而是让人在 30 秒内看懂：

> 一句话 / 整本小说 → 章节解析 → 实体确认 → 12 集分集 → 逐集剧本 → 资产与分镜 → 画面 → 配音 → 质检审核 → 时间线与导出

每一个步骤都是一次模型调用：有输入契约、有唯一产物、有费用与耗时，成功才解锁下一步，失败保留诊断码并可以改参数重跑。小说改编不是“一键全自动”：一次导入，三次确认（章节边界、人物实体、分集钩子），再批量生成逐集剧本。

**制作链路深度评估见 [`PRODUCTION_CHAIN_AUDIT.md`](PRODUCTION_CHAIN_AUDIT.md)**：包含 12 阶段盘点、P0/P1/P2 缺口与下一步优先级。

**逐环节功能与交互设计见 [`PRODUCTION_FUNCTION_DESIGN.md`](PRODUCTION_FUNCTION_DESIGN.md)**：对象模型、状态机、12 环节交互、状态同步矩阵与验收脚本。

## 打开方式

直接双击 `index.html`，无需安装、无需起服务。推荐 Chrome / Edge，窗口 1440×900 以上。

演示账号（登录页任意密码均可进入）：`chenmo@studio.cn`。

演示项目：`长夜将明 / NYJM-26 / 12 集 / 竖屏 9:16 / 30fps / EP01 雨夜书店`。

## 主题与全局交互

- 顶栏日 / 月按钮切换暗色与亮色；选择写入 `sp_v2_theme`，16 个页面与登录页统一跟随，刷新与跨标签页都保持。
- 预览链接可强制主题：`?theme=light` / `?theme=dark`，并写入偏好，后续页面继续沿用。
- 顶栏搜索打开「快速查找」，可搜页面、能力与集数，Enter 打开第一个结果。
- 顶栏通知进入任务中心；顶栏头像与左栏设置进入团队设置。
- 审核页镜头批注“转返工”会写入 `sp_v2_rework`，任务中心读取并显示返工任务。

## 导航层级

左侧是全局导航，按职责分组；顶部只保留“单集工作区”，不再与左侧重复。

| 层级 | 位置 | 负责什么 | 包含 |
|---|---|---|---|
| 全局 | 左侧栏 | 跨项目、跨集的入口 | 项目：项目库 / 项目总览；内容：分集总览 / 故事圣经 / 资产库；协作：任务中心 / 审核队列；配置：模型接入 / 成本用量 / 团队设置 |
| 单集 | 顶部条 | 当前这一集的深视图 | 本集制作 / 剧本 / 分镜 / 配音 / 时间线 |

项目库、分集、任务、审核等全局页面不显示顶部单集条；只有制作台、剧本、分镜、配音、时间线显示。

## 一条链，七个步骤

| # | 步骤 | 模型 | 产物 | 人工动作 |
|---|---|---|---|---|
| 01 | 设定与故事 | `mork-llm-7b` | 故事圣经 v5 + 12 条分集钩子 | 选素材来源、确认人物关系 |
| 02 | 剧本与分集 | `mork-llm-7b` | 12 集大纲 + EP01 剧本 v6（8 场 / 19 条对白） | 改台词、AI 优化本场、锁版本 |
| 03 | 资产与分镜 | `mork-image-3` + `mork-llm-7b` | 63 项资产 / 24 个 Shot Contract | 选参考图、锁定引用、确认镜头 |
| 04 | 画面生成 | `mork-video-2` | 21 段竖屏画面 | 选画幅与并发、失败后重跑 |
| 05 | 配音与字幕 | `moss-tts-cn` + `mork-llm-7b` | 19 条对白音轨 + SRT | 试听、单条重录、字幕重排 |
| 06 | 质检与审核 | `qa-rules-2026.11` + `vision.qa` | QA 92/100 | 通过 / 退回修改 |
| 07 | 时间线与导出 | `Timeline Assembler` + `FFmpeg` | `EP01_v6.mp4` | 调轨道、导出、下载 |

QA 是唯一的人工 gate：通过后 `导出` 解锁；退回则回到 `质检待处理`，导出被锁定。

小说的三次确认发生在 02 之前：`import.html` 切章与实体确认 → `episodes.html` 分集与钩子确认 → 逐集 `script.html` 锁版。确认一次，后面才能批量生成。

## 10 分钟评审路线

**小说改编路径（新增，建议先走）**

1. `index.html` 点「新建短剧」→「导入小说改编」：看 24 章示例、双模式分流。
2. 点「解析小说并进入」到 `import.html`：切章、点「边界校对」拆分/并入一章并撤销、验收边界，再确认实体、把“他”合并到周砚。
3. 打开「故事圣经」改一条小传、新增一条关系、保存 v5，再回分集页。
4. 解析进度完成后落到 `episodes.html`：看 12 集季卡，点「章节映射」逐章改归属并保存 v3，再点「批量生成剧本」→ 9 集逐一变成草稿。
5. 点 EP03/EP05「打开剧本」到 `script.html?ep=03`：顶部 12 集 chips 切换，锁版后回分集页状态同步。
6. 回 `episodes.html` 点任一集「打开剧本」，再回 `studio.html` 按集推进 03–07。

**单集生产路径**

1. `index.html`：hero 左下角七步流程条，当前停在 04 画面。
2. 点「继续制作 EP01」进入 `studio.html`，看 01–03 已完成、04 待生成、05–07 锁定。
3. 在 04 点「生成此步」：进度、日志、费用跑完后解锁 05。
4. 把画幅从 `9:16` 改成 `16:9` 再生成：得到 `QA_FRAME_RATIO_MISMATCH` 失败；点「按 9:16 重跑」恢复。
5. 打开「专业视图」：剧本、资产、分镜、配音、审核、时间线都是同一份数据的深视图。
6. 在 `review.html` 点「通过」：`studio.html` 的 06 变已完成、07 变待生成；回到 `timeline.html` 导出即可。
7. 任意页面右侧栏可看到这一步用的模型、输入、计费与产物版本。

## 设计语言

- 暗色电影控制室：近黑 `#08090b`、面板 `#111317`、细线 `#262b32`、骨白 `#ece7de`、单一钨丝橙 `#f05a2a`。
- 状态只有五种颜色语义：绿=完成、黄=待处理、红=失败/需重录、橙=当前、灰=锁定。
- 剧本正文使用米色纸张 `#f0eadd` 与衬线字，和暗色工作台形成强对比，明确「内容」与「工具」的边界。
- 所有剧照为 9:16 电影感素材，真实画面承担情绪，界面只负责操作与状态。

## 状态与重置

制作台状态写在 `localStorage` 的 `sp_v2_state`：

```json
{
  "steps": { "setup": "done", "script": "done", "assets": "done", "render": "pending", "voice": "locked", "qa": "locked", "export": "locked" },
  "current": "render",
  "inputs": {},
  "ratio": "9:16",
  "accepted": false,
  "log": []
}
```

分集状态写在 `sp_v2_eps`：

```json
[
  { "no": "01", "status": "locked" },
  { "no": "04", "status": "pending" },
  { "no": "05", "status": "draft" }
]
```

`episodes.html` 每次渲染都会写入 `sp_v2_eps`；`script.html` 读写它，决定 12 集 chips 哪些可打开、哪些仍是待生成，并把保存/锁版状态同步回分集页。点制作台右上角「重置」可恢复 `sp_v2_state` 初始演示状态，分集状态需清浏览器 `localStorage`。

## 已知边界

- 全部生成、审核、导出均为前端模拟，不产生真实模型调用与真实视频文件；导出的 MP4 为演示结果卡，SRT 与账单 CSV 可真实下载。
- 任务进度与耗时为演示数值，用于表达交互节奏，不代表真实推理性能。
- `episodes.html` 的 12 集与 `import.html` 的 24 章为前端常量；EP04–12 的剧本由通用模板即时拼装，只用于证明“批量生成后可打开任一集”，不代表真实文本质量。
- 分集状态存在 `localStorage`，不接后端；真实系统需 `Episode / Script / ScriptVersion` 按集 API。详见 `PRODUCTION_CHAIN_AUDIT.md`。
- 页面之间共享的是演示状态，不接后端接口；接入真实 `web/` 时按相同字段替换即可。
- 项目库中除《长夜将明》外的三张卡片是展厅样例，用于展示不同项目状态；点击会提示，不承载独立数据。
