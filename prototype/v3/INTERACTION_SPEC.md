# 核心流程与交互规格

## 1. 全局交互约定
- 导航：企业层为全局侧栏；项目内侧栏按创作/生产/交付分组；面包屑显示项目和当前模块。点击菜单切换路由；项目选择器变更项目上下文，abort 旧请求、清理缓存/订阅，再访问新项目。
- 顶栏：全局搜索（项目内检索只限当前 project_id）、通知、帮助、用户菜单；搜索结果必须按权限过滤。
- 操作：主按钮置于标题区右侧；次操作在工具栏；危险操作使用确认弹窗；详情和创建/编辑使用右侧抽屉；长文本/专项编辑使用独立工作区。
- 表单：标签常驻；必填星号；字段错误就近展示；提交期间按钮 loading 且禁重复；服务端 422 显示字段映射，409 显示版本冲突；所有成功提示须等服务端确认。当前 HTML 交互仅为本地演示。
- 资源：资产引用固定 asset_version_id；跨项目引用拒绝。版本更新后下游 stale，不自动替换。
- 访问：401 清会话回登录并保留 redirect；403 展示无权访问；404 展示不存在；API 不可用 fail closed。前端隐藏按钮不是授权控制。

## 2. 关键业务主链路
创意/故事圣经 → 剧集 → 剧本版本 → 场次/对白 → 角色/场景/道具资产 → 分镜板/镜头 → Shot Contract Version → AI Task/Attempt/Artifact → QA → 人工审核/返工 → TimelineVersion → ExportJob → ffprobe/解码/checksum → MP4 交付归档。

### 2.1 创意与剧本
1. 从故事圣经点“新建故事”，输入标题、题材、梗概、主题；标题必填 2–80 字，梗概必填 20–5000 字。
2. 保存草稿后创建圣经版本：世界观、核心规则、人物关系、风格参考；版本只增不改。
3. 新建剧集：序号正整数且项目内唯一；标题 1–80 字；预计时长 1–60 分钟。
4. 剧本编辑：场次编号在剧本内唯一；对白角色必须关联角色资产；保存传 base_version/If-Match。
5. 409：保留本地草稿，显示远端版本号、差异和“重新加载/另存为新版本”；不得静默覆盖。
6. 上游故事/角色/场景变化显示影响对象清单，用户确认后再继续。

### 2.2 资产上传与版本
1. 上传前选资产类型、文件；支持 PDF/DOCX/TXT/MD/CSV/JSON/SRT/VTT/PNG/JPEG/WebP/MP3/WAV/MP4/MOV；浏览器预检仅为提示，服务端必须复验 magic bytes、MIME、大小、配额。
2. 上传过程：待上传→上传中→隔离扫描→探测中→ready/invalid；扫描完成前禁止下游引用。
3. 文件超限/类型伪装/扫描失败：保留失败状态和 request_id，提供重新选择/重试，不显示预览下载。
4. 创建新版本时保留旧版本；引用固定版本。被引用资产禁止物理删除。
5. 下载每次鉴权，使用短时 URL，不暴露对象存储凭据。

### 2.3 Shot Contract 与 AI 生成
1. 从镜头详情选择已保存的 Contract Version。
2. 选择 capability（image/video/audio/text）；Provider/模型仅展示服务端能力目录返回的值。
3. 参数按模型 schema 动态呈现；时长、画幅、分辨率、seed 等范围从 schema 取值，不在前端猜。
4. 提交需 project write 权限、预算校验、Mork 配置、幂等键；未配置 Mork 返回 `PROVIDER_NOT_CONFIGURED`，不允许 fallback Mock。
5. 成功返回 task_id 后显示 queued；以任务快照为最终事实，SSE 仅通知；成功需存在已校验 Artifact。
6. 429/5xx 有界退避重试；权限/策略/参数错误不重试；取消使用 cancel_requested 协作语义。

### 2.4 QA / 审核 / 返工
1. QA 绑定不可变 subject_version_id + rule_set_version。
2. 结果只有 PASS、REVIEW_REQUIRED、FAIL；服务不可用不允许默认 PASS；FAIL 阻断后续发布/剪辑。
3. REVIEW_REQUIRED 进入人工队列；项目统一 review permission，无多级会签。
4. 审核预览对象具体版本，填写决定与理由；拒绝必须 reason 10–1000 字。
5. 通过后状态 approved；拒绝创建返工任务。返工必须产生新版本并重新 QA/审核；旧审核结论不继承。无 WAIVED/豁免。

### 2.5 时间线与导出
1. 仅选择当前项目且已审核的 AssetVersion；轨道类型 video/audio/subtitle/overlay。
2. 视频按整数帧序号、音频按整数采样点；持久化/API 权威时间为整数 PTS + 有理数 time_base，禁止浮点秒。
3. clip source_in/source_out/timeline_start 校验非负、source_out 大于 source_in 且不越界；素材 stale/缺失时阻断提交。
4. 保存创建不可变 TimelineVersion；409 提示冲突；旧版本可查看/恢复。
5. 导出选择时间线版本和白名单 profile，冻结引用快照；排队→渲染→校验→成功/失败。
6. 成功前必须 ffprobe、完整解码、checksum 全通过；失败不展示下载；成功产物不可覆盖旧版。

## 3. 抽屉、弹窗与反馈
| 组件 | 触发 | 内容 | 校验/结果 |
|---|---|---|---|
| 创建/编辑抽屉 | 页面主按钮/行编辑 | 对象字段、必填、帮助文案 | 校验后提交；成功关闭并刷新列表 |
| 详情抽屉 | 点击行/详情 | 元数据、版本、关联、审计 | 只读；按权限显示动作 |
| 成员管理抽屉 | 项目行/项目设置 | 用户、项目角色、状态 | 不可移除 owner；移除二次确认 |
| 上传弹窗 | 资产页上传 | 类型、文件、校验提示、进度 | MIME/大小/扫描失败显示错误；未 ready 不可引用 |
| 生成任务弹窗 | Shot Contract “生成” | 能力、Provider、模型、参数、预算估算 | 未配置 Provider 阻断；幂等防重复 |
| 审核决策弹窗 | 审核详情 | 对象版本、QA 问题、决定、原因 | 拒绝原因 10–1000 字；确认后生成审计 |
| 取消/归档确认 | 危险操作 | 影响范围、不可逆提示 | 必须二次确认 |
| 版本冲突弹窗 | 409 | 本地/远端版本、差异摘要 | 重载/另存；不可静默覆盖 |
| stale 提示 | 上游版本变化 | 变更源、受影响镜头/时间线 | 用户明确确认后更新引用 |

## 4. 统一空/错/加载状态文案
- loading：骨架行/卡片；按钮显示“处理中…”，禁止重复提交。
- empty：图标 + “还没有内容” + 当前角色可执行的“新建/上传/导入”入口。
- error： “加载失败，请稍后重试”；展示错误码、request_id、重试；不展示堆栈。
- forbidden： “无权访问此项目”，不渲染业务内容。
- not_found： “内容不存在或已被移除”。
- conflict： “当前内容已被其他版本更新”，提供比较和重载。
- stale： “引用的上游版本已更新”，列出受影响对象，需人工确认。
- processing：阶段、百分比（仅服务端返回）、最近更新时间。
- success：只有服务端确认后展示；失败不出现“已完成”。
- unsaved：离开时弹窗“保存更改 / 丢弃更改 / 继续编辑”。

## 5. 表单字段与规则索引
| 表单 | 必填/约束 |
|---|---|
| 用户 | 姓名 2–80；邮箱合法且唯一；状态 active/disabled；角色至少一个（按业务策略） |
| 组织/部门 | 名称 2–80；编码唯一；上级部门不得形成循环 |
| 角色 | 名称 2–60；编码小写字母/数字/下划线；权限来自服务端目录 |
| 项目 | 名称 2–80；编码唯一；描述 ≤2000；成员需显式授权 |
| 故事 | 标题 2–80；题材受控词表；梗概 20–5000 |
| 剧集 | 序号正整数且唯一；标题 1–80；时长 1–60 分钟 |
| 资产 | 类型、文件必填；项目归属不可修改；引用资产不可物理删除 |
| Shot Contract | 镜头序号唯一；时长 >0；景别/机位/动作必填；资产版本必须同项目 |
| 审核 | subject_version_id 固定；拒绝原因 10–1000 |
| Timeline Clip | PTS 非负；duration >0；source_out > source_in；不允许越界 |
| Export | TimelineVersion + 白名单 profile 必填；未通过审核或存在 stale 引用阻断 |
