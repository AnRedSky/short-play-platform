Interaction states

交互状态规范

每个列表、详情、编辑页都必须实现以下状态。页面不允许出现“空白即无数据”，也不允许把 403 伪装成空列表；成功必须以服务端返回为准。

原型演示数据 · 未接后端

loading

加载中
规则：骨架或明确加载指示，超过 400ms 才显示，避免闪烁；禁止用空白代替加载态。

empty

真实无数据
还没有镜头

从剧本场次拆镜，或手动创建第一个 Shot。

规则：说明“为什么空”并提供有权限的下一步；无权限时不得显示可点击的创建入口。

error

可重试
加载任务失败　上游返回 502，已自动重试 2 次。request_id req_4c91a2
规则：展示 request_id 与可重试提示；不泄露堆栈、SQL 或内部路径。

forbidden

403
无法访问此项目

你的账号不属于该项目成员，或项目角色未授予读取权限。

403 · projects:read
规则：明确提示权限不足；不得伪装成空列表，也不得暴露项目是否存在。

not_found

404
资源不存在或已被归档

该版本可能已被撤回。历史审核与导出记录仍可在审计中查询。

规则：不泄露其他项目中是否存在同名资源；提供返回路径。

conflict

409
版本冲突 base v5 → server v6
YOURS

SCENE 2 对白改写

THEIRS

SCENE 3 新增对白

规则：展示差异与两个动作，不以后写覆盖前写；本地内容可存为草稿，不丢失。

stale

依赖失效
上游已更新：角色 · 沈砚 v3　引用 v2 的 12 个镜头被标记 stale；已交付版本保持有效。
规则：显式列出受影响对象；不静默覆盖、不自动无限重跑（尤其已产生费用）。

processing

长任务
渲染中 · 68%updated 8s ago

状态以服务端快照为准；SSE 断开后自动重拉，不依赖事件流判断完成。

规则：显示阶段与最后更新时间；长任务不阻塞页面，允许离开后回来查看。

success

已确认
已创建 TimelineVersion v5
规则：只在服务端确认后提示成功；生成类必须有真实 Artifact / AssetVersion，不能只有前端状态。

unsaved

未保存离开

有未保存的修改

离开后本次修改不会保留。保存会生成新的不可变版本。
规则：离开编辑器前必须确认；保存与丢弃都需明确选择，不允许静默丢失内容。

demo / mock

演示标识
原型演示数据 · 未接后端

仅在显式开发配置下启用；生产环境不允许 Mock 伪装真实结果。

规则：演示数据页持续展示标识；Mock 不得出现在生产构建，也不得写入后端。

offline / 断线

网络中断
与服务器断开连接。已停止轮询，恢复后自动重拉最新快照。
reconnecting… attempt 2 / 5
规则：明确区分“断线”与“服务错误”；断线期间禁用写操作，避免重复提交。
