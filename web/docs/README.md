# 前端文档索引

本目录只维护前端设计、交互、接口对接、重建方案和测试文档。产品需求与领域规则仍以仓库根目录的正式方案为准，前端实现细节以本目录为准。

## 当前文档

前端重建方案：重建边界、目标分层、核心业务对象、状态机原则、页面职责、模拟数据边界、实施顺序与清理标准。

功能契约模板：任何前端功能进入开发前必须填写的最小契约。

项目概览垂直切片：第一个重建切片的范围、对象、页面行为、验收步骤和当前实现状态。

文件位置如下：

```text
rebuild/前端重建方案.md
rebuild/功能契约模板.md
rebuild/项目概览垂直切片.md
```

## 目录约定

重建目录用于存放重建方案、功能契约、垂直切片说明和验收记录。

归档目录用于存放已停止维护的旧前端文档，只作历史参考，不再作为实现依据。

后续新增模块文档按“业务域/流程名”建立子目录，不把多个流程混在一份文档里。

目录位置如下：

```text
rebuild/
archive/
```

## 归档说明

旧版页面映射和接口清单已移入归档目录。这些文档描述的是旧模拟实现，不再作为新链路的实现依据。新链路需要接口说明时，在重建目录下按业务域补充契约，不直接修改归档文档。
