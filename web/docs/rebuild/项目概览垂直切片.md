# 项目概览垂直切片

- 状态：已实现，待验收
- 所属流程：项目与单集阶段推导
- 页面入口：见下方代码块
- 验收地址：本地预览服务下的重建版项目概览

```text
/studio/projects
```

## 一、切片目标

用一个新的项目概览页面验证重建后的基础链路，证明下面四件事可以同时成立：

1. 项目阶段由单集状态自动推导，不再手工推进项目阶段。
2. 单集八个执行阶段的状态机可以独立运行。
3. 页面只负责展示和调用用例，不直接拼装业务状态。
4. 模拟数据只通过仓储适配层进入页面，不再由页面直接维护业务状态。

## 二、本次范围

本次只做项目概览与单集阶段展示，不包含剧本编辑、导演规划、素材生产、剪辑、声音字幕、质检和交付的真实页面。

本次已实现：

1. 项目列表与项目切换。
2. 项目当前阶段、进度、活跃单集、已交付集数。
3. 批次与单集卡片。
4. 单集八个执行阶段的阶段链。
5. 单集事实状态展示。
6. 单集下一步动作与执行推进。
7. 项目级治理动作：暂停、恢复、终止、归档。
8. 重置验证数据。

本次不实现：

1. 项目创建与成员授权。
2. 剧本、镜头、资产、任务和交付对象的真实编辑。
3. 真实后端接口。
4. 跨集视觉基线和一致性质检。
5. 旧页面的删除或替换。

## 三、核心对象

本次使用新的领域对象：

1. 项目：名称、简介、生命周期、批次、单集、时间。
2. 批次：批次序号、名称、包含的单集编号。
3. 单集：单集编号、标题、剧本版本、计划版本、基线版本、事实状态。
4. 单集事实状态：输入确认、剧本锁定、镜头与资产锁定、素材生产启动、素材生产完成、剪辑完成、声音完成、字幕确认、质检通过、已交付、阻断状态。

## 四、阶段推导规则

单集当前阶段按事实状态从后向前判断：

1. 已交付：终审入库，完成。
2. 质检通过：终审入库。
3. 字幕确认：单集质检。
4. 声音完成：声音字幕。
5. 剪辑完成：声音字幕。
6. 素材生产完成：剪辑。
7. 素材生产启动：素材生产。
8. 镜头与资产锁定：素材生产，等待启动。
9. 剧本锁定：镜头与资产。
10. 输入确认：剧本锁定。
11. 其余情况：输入确认。

项目当前阶段取所有未交付单集中阶段最靠前的一集。单集交付后不再参与项目阶段推导。

## 五、页面行为

1. 左侧项目列表用于切换项目。
2. 顶部显示项目当前阶段、进度、活跃单集和已交付集数。
3. 批次区域展示每个批次的单集卡片和单集当前阶段。
4. 选中单集后展示八个阶段的阶段链和事实状态。
5. “下一步动作”只显示当前状态允许的一个动作，不允许跳过阶段。
6. 项目级只显示治理动作，不显示生产推进按钮。
7. 执行动作后立即刷新项目与单集状态，页面提示当前阶段。

## 六、数据访问边界

```text
页面 -> 应用用例 -> 项目仓储接口 -> 模拟项目仓储
```

约束：

1. 页面不直接读写浏览器存储。
2. 模拟项目仓储只负责读取、保存和重置验证数据。
3. 阶段推导、下一步动作和治理动作在领域层与应用层完成。
4. 后续接入真实后端时，只替换仓储实现，不修改页面和领域规则。

## 七、验收步骤

1. 打开重建版项目概览页面。
2. 确认默认项目为“雾城来信”，当前阶段为“素材生产”，进度为百分之六十七。
3. 确认第 1 集为“终审入库”，第 2 集为“声音字幕”，第 3 集为“素材生产”。
4. 选中第 3 集，确认阶段链高亮“素材生产”。
5. 点击“执行并刷新”，确认提示“当前阶段为剪辑”，项目阶段变为“剪辑”。
6. 确认第 3 集下一步动作变为“完成剪辑”。
7. 点击“暂停项目”，确认项目状态变为“已暂停”，治理动作变为恢复、终止、归档。
8. 点击“重置验证数据”，确认恢复初始状态。
