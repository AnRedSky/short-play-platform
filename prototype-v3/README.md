# Prototype V3｜短剧平台高保真交互原型

> 基线分支：develop · 基线提交：51bbbd3f4bcb36bda34f5c0dafc01491f164d00c  
> 类型：前端设计参考原型（纯静态数据，不调用生产 API、不产生真实业务写入）  
> 入口：[`index.html`](./index.html)

## 交付内容
- `index.html`：可点击高保真桌面端管理工作台，包含全局导航、项目空间、业务页面、表单、抽屉、弹窗、状态切换和模拟操作反馈。
- `PAGE_CATALOG.md`：按模块/二级菜单逐项映射的页面清单、布局、字段、权限及页面跳转。
- `INTERACTION_SPEC.md`：关键业务流程、表单校验、弹窗/抽屉、加载/空/异常/冲突/stale 状态。
- `DESIGN_SYSTEM.md`：设计 token、组件规范、断点和响应式规则。
- `TRACEABILITY.md`：与当前功能清单、路由/API 现状的追踪矩阵和未实现能力边界。

## 预览
直接用浏览器打开 `index.html`。建议桌面 1440×900；无构建依赖、无需服务端。侧边栏、顶部项目切换、菜单、搜索、筛选、分页、创建/编辑抽屉、详情弹窗、确认框、通知和模拟状态均可交互。

## 重要边界
该原型用于确认信息架构、视觉和交互，不代表 API 或后端能力已经实现。所有样例记录均为合成数据；按钮只在浏览器内模拟。尚无 API 的 QA/审核、时间线、导出管理、Provider 配置、预算、通知等功能均显式标注“目标交互 / 待后端契约”，不得直接据此宣称生产闭环可用。Mork 未配置必须失败关闭，禁止 Mock 回退；权限以服务端为准；所有生产资源均按 project_id 隔离。
