# 项目规则

## 一、语言规范

1. 所有面向用户的说明、方案、总结、验收记录、需求描述、文档正文和界面文案，统一使用规范中文完整表达。
2. 中文语句中不得夹杂英文单词、英文缩写、专业英文简写，也不得出现与中文混排的非中文字母符号。
3. 阶段、版本、基线、任务、产物等业务概念一律使用中文全称，例如“第二执行阶段”“镜头计划版本”“视觉基线”“候选镜头版本”，不得用字母代号代替。
4. 同一概念首次出现使用中文全称，后续可使用明确、统一的中文简称。
5. 句子应完整、通顺、主谓明确，避免只写关键词、英文式倒装和生硬直译。
6. 标点统一使用中文标点，数字与中文之间按中文排版习惯处理。

## 二、技术标识的处理

1. 代码、命令、文件路径、接口字段、数据库字段、程序标识等必须保留原始写法的内容，只能放在独立代码块中。
2. 上述原始标识不得直接嵌入中文句子，不得用括号夹在中文词语后面冒充业务名称。
3. 正文解释技术标识时，先给出中文含义，再在独立代码块中列出原始写法。
4. 页面提示、按钮、错误信息、验收说明和提交说明属于用户可见文本，应优先使用中文；技术原始信息可另起代码块保留。

## 三、适用范围

1. 适用于需求分析、方案设计、流程梳理、开发说明、验收报告、问题排查、代码注释、提交说明、文档标题与正文。
2. 代码本身、第三方原始日志、外部系统强制要求的字段不受此规则约束，但引用时必须用中文说明其作用。
3. 本规则与旧有英文命名习惯冲突时，以本规则为准；代码内部标识和既有接口字段暂不强制重命名。

## 四、检查要求

1. 交付前检查正文是否出现非中文词语或字母缩写。
2. 发现英文缩写时，改写为中文全称或中文简称。
3. 发现中英文混排的技术标识时，移入独立代码块并补充中文解释。
